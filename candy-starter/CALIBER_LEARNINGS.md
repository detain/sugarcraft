# Caliber Learnings

Accumulated patterns and anti-patterns from development sessions.
Auto-managed by [caliber](https://github.com/caliber-ai-org/ai-setup) — do not edit manually.

- **[convention:candy-starter]** candy-starter is `composer type: project` (a create-project skeleton), NOT `type: library` like its 51 siblings. Its namespaces are deliberately `App\` / `App\Tests\` (`src/Counter.php`, `tests/CounterTest.php`) — a sanctioned deviation from the `SugarCraft\<Lib>` PSR-4 rulebook so that code forked downstream keeps the user's app namespace. Never "fix" these namespaces, and never register the starter's classes under a `SugarCraft\*` alias.
- **[pattern:candy-starter-docs-as-code]** The template IS its own tutorial: `src/Counter.php`'s class docblock is the "read in one screen" walkthrough (Elm pattern, immutability, `Cmd::quit()`), ending with the numbered "To extend: 1. field, 2. Msg handler, 3. view(), 4. test matrix" recipe, `bin/start`'s header tells the forker exactly which line to swap, and the README's "Anatomy of a SugarCraft Model" fence is the contract reference. Two guards keep the tutorial honest — `tests/ReadmeSnippetsTest.php` lints AND executes every fenced php README block in a bounded child process, and `tests/ModelContractDocumentationTest.php` Reflection-derives `Model`'s required members and pins them against the fence. Change the contract or the fence, and one of them reddens. Keep every template file readable in one screen — length is a defect here, terseness is the feature.
- **[pattern:candy-starter-quit-semantics]** Exact quit matrix, pinned by `tests/CounterTest.php`: plain `q` quits; **alt+q also quits** because `shouldQuit()` excludes only `ctrl` (`testAltQTriggersQuit`); Shift+q = rune `'Q'` does NOT quit (`testShiftQDoesNotQuit`); Escape quits **regardless of modifiers** — `testAltEscapeStillQuits`/`testShiftEscapeStillQuits` (corrected 2026-10-23: these were the long-lived `…DoesNotQuit` misnomers whose bodies always asserted the non-null quit cmd; renamed truthfully in the docs-fix-1023 sweep, behavior unchanged); `ctrl+c` quits; every other ctrl combo is inert. When extending the template, copy the rune-exact comparisons — the modifier gaps are intentional teaching surface.
- **[gotcha:candy-starter-audit-vs-tests]** `findings/candy-starter.md` (2026-06-30) Findings 1–3 prescribe `strtolower()` rune normalization and claim "upstream Bubble Tea quit is rune-insensitive"; `findings/plan_candy-starter.md` Phase 1.1 repeats it. The committed test suite pins the OPPOSITE behavior as deliberate. Do not apply that plan phase blindly — reconcile intent with the pins first (this file's [pattern:candy-starter-quit-semantics] row is the reconciliation).
- **[gotcha:candy-starter-subscriptions]** `Model::subscriptions()` is an abstract contract member, not optional: commit d67be88b2 had to sweep `subscriptions(): ?Subscriptions { return null; }` stubs across 32 models. A new skeleton model that omits it is an instant fatal; returning `null` means "static subscription set".
- **[pattern:candy-starter-instanceof]** `if ($msg instanceof KeyMsg === false)` (`src/Counter.php:46`) is the house shape after commit 60577d747 swept implicit-boolean/`!`-with-`instanceof` Codacy complaints repo-wide — write `=== false`, not `!($x instanceof Y)`.
- **[pattern:candy-starter-overflow-teaching]** Boundary tests live at `PHP_INT_MAX - 1` / `PHP_INT_MIN + 1` with the in-file warning "PHP integer math wraps to float on overflow" (`CounterTest.php:475`) — an overflowing counter silently becomes a float and breaks the `int` type of the promoted readonly ctor. Keep any new numeric demo field pinned one step inside the boundary.
- **[bug:candy-starter-style-rebuild]** OPEN MEDIUM (`findings/candy-starter.md` Finding 4, `plan_candy-starter.md` Phase 2 not-started): `view()` rebuilds `Style::new()->border(Border::rounded())->padding(1,2)` on every frame — three throwaway `Style` objects per render. Negligible for the demo, but the template therefore *teaches* a per-frame-build anti-pattern; the planned fix is a memoized `private static ?Style` and a doc note. Re-confirmed open 2026-10-23 (docs-fix-1023 review): memoization still unshipped. Until shipped, do not cite the template's `view()` as the reference for real apps — cite sugar-widgets widgets instead.

- **[pattern:candy-starter-panic-optin]** The crash handler is opt-in by design: `Log::installPanicHandler()` ships commented in `bin/start` because sugar-log is NOT a template dependency (pulling it would force `composer require sugarcraft/sugar-log`, and in-monorepo a path-repo note too). README used to overstate it as default — fixed in 7ff64eeb1 together with the PHP badge; keep docs aligned to the commented-by-default reality.
- **[convention:candy-starter-deps]** Sibling deps (`sugarcraft/sugar-core`, `sugarcraft/sugar-style`, `dev-master`) resolve from Packagist; per-lib `repositories[]` path-repo blocks were swept out (b8b1dbeba, 2fa678a7f) and are re-injected by CI only — never commit one into `candy-starter/composer.json` (it would break every `create-project` consumer). Note candy-starter's constraint is `php: >=8.3` (project flavor), while libraries pin `^8.3`.
- **[env:candy-starter-phpunit]** `phpunit.xml` CARRIES `failOnWarning="true"`. (Truth-corrected 2026-10-23, docs-fix-1023 M1: this row once claimed the attribute was deliberately absent after c8fcf8c56 — stale: 59ec5a6e3 re-added it during the E738 adoption sweep and it has survived every change since; the AGENTS.md skeleton snippet and this file now agree.) There is no `tests/bootstrap.php` because `Counter` arms no timers. Add the `LoopPin::pinStableClock()` bootstrap (sugar-async family) only if a future demo grows timer-bounded waits.
- **[pattern:candy-starter-coverage-style]** 863ded99d "boost coverage" grew the suite to 59 exhaustive test methods over a 92-line `Counter.php` (full rune × modifier matrix for quit paths, `testNumbersAsRunes`/`testSymbolRunes`/`testEmptyRuneWithCharType`, `testIntegerBoundaryPositive/Negative`, `testViewRenderingDoesNotAffectState` purity pin). For a template this breadth doubles as the living reference for the "every public method ≥1 test" law — when extending the model, extend the matrix, not just happy paths.
