# Caliber Learnings

Auto-managed by [caliber](https://github.com/caliber-ai-org/ai-setup) — do not edit manually.

- **[convention:candy-starter]** candy-starter is `composer type: project` (a create-project skeleton), NOT `type: library` like its 51 siblings. Its namespaces are deliberately `App\` / `App\Tests\` (`src/Counter.php`, `tests/CounterTest.php`) — a sanctioned deviation from the `SugarCraft\<Lib>` PSR-4 rulebook so that code forked downstream keeps the user's app namespace. Never "fix" these namespaces, and never register the starter's classes under a `SugarCraft\*` alias.
- **[pattern:candy-starter-docs-as-code]** The template IS its own tutorial: `src/Counter.php`'s class docblock is the "read in one screen" walkthrough (Elm pattern, immutability, `Cmd::quit()`), ending with the numbered "To extend: 1. field, 2. Msg handler, 3. view(), 4. test matrix" recipe, `bin/start`'s header tells the forker exactly which line to swap, and the README's "Anatomy of a SugarCraft Model" fence is the contract reference. Two guards keep the tutorial honest — `tests/ReadmeSnippetsTest.php` lints AND executes every fenced php README block in a bounded child process, and `tests/ModelContractDocumentationTest.php` Reflection-derives `Model`'s required members and pins them against the fence. Change the contract or the fence, and one of them reddens. Keep every template file readable in one screen — length is a defect here, terseness is the feature.
- **[pattern:candy-starter-quit-semantics]** Exact quit matrix, pinned by `tests/CounterTest.php`: plain `q` quits; **alt+q also quits** because `shouldQuit()` excludes only `ctrl` (`testAltQTriggersQuit`); Shift+q = rune `'Q'` does NOT quit (`testShiftQDoesNotQuit`); Escape quits **regardless of modifiers** — `testAltEscapeStillQuits`/`testShiftEscapeStillQuits` (corrected 2026-10-23: these were the long-lived `…DoesNotQuit` misnomers whose bodies always asserted the non-null quit cmd; renamed truthfully in the docs-fix-1023 sweep, behavior unchanged); `ctrl+c` quits; every other ctrl combo is inert. When extending the template, copy the rune-exact comparisons — the modifier gaps are intentional teaching surface.

- **[gotcha:candy-starter-subscriptions]** `Model::subscriptions()` is an abstract contract member, not optional: commit d67be88b2 had to sweep `subscriptions(): ?Subscriptions { return null; }` stubs across 32 models. A new skeleton model that omits it is an instant fatal; returning `null` means "static subscription set".
- **[pattern:candy-starter-instanceof]** `if ($msg instanceof KeyMsg === false)` (`src/Counter.php`, top of `update()`) is the house shape after commit 60577d747 swept implicit-boolean/`!`-with-`instanceof` Codacy complaints repo-wide — write `=== false`, not `!($x instanceof Y)`.
- **[gotcha:candy-starter-overflow-teaching]** Boundary tests live at `PHP_INT_MAX - 1` / `PHP_INT_MIN + 1` with the in-file warning (near `testIntegerBoundaryPositive`) — under `declare(strict_types=1)` an overflowing counter does NOT "silently become a float": the float result reaching the promoted `int` property raises an uncaught `TypeError`, so the death is loud but ugly. Pin new numeric demo fields one step inside the boundary rather than testing the crash. (Truth-corrected 2026-11-03, lib-reviews-1102 senior/security/tui cluster: the old "silently becomes a float" wording described non-strict typing.)

- **[env:candy-starter-autoload]** `bin/start` resolves the autoloader with ONE script-rooted check — `is_file(__DIR__ . - **[pattern:candy-starter-panic-optin]** The crash handler is opt-in by design: `Log::installPanicHandler()` ships commented in `bin/start` because sugar-log is NOT a template dependency (pulling it would force `composer require sugarcraft/sugar-log`, and in-monorepo a path-repo note too). - **[pattern:candy-starter-exit-tail]** The reference bin ends with the captured-`stopSignal()` tail — cooperative stops (QuitMsg, kill(), model-raised InterruptMsg) keep exit 0; SIGINT/SIGTERM/SIGHUP-stopped runs `exit(128 + N)` (130/143/129). sugar-core owns the accessor contract; the starter owns the COPY obligation, pinned by shape in `tests/BinStartExitTailTest.php` (lib-reviews-1102 architect M2/qa M2: before 2026-11-03 the bin discarded the stop reason, so every fork inherited signal-blindness). Keep this tail when you swap the Model.
