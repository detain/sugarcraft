Twenty-two apps built on the stack.

Standalone executables — CLI tools (prompts, markdown, screenshots), full TUIs (file manager, git, SQLite, AI chat, games), and a project starter — the starter you scaffold, not install. Install via Composer, run as a CLI binary. Each has a detail page below with controls, architecture, and demo recordings.

CandyStarter

GitHub →

composer create-project sugarcraft/candy-starter my-app --stability=dev — scaffold a working app from the counter Model (Packagist carries only dev-master until a candy-starter/* tag exists).

CandyScriptui

GitHub →

Composer-installable CLI of thirteen subcommands — choose, confirm, file, filter, format, input, join, log, pager, spin, style, table, write.

CandyCodeshot

GitHub →

Code → SVG screenshot. Traffic-light window controls, drop shadow, gutter line numbers, ANSI SGR parsing. No GD / Imagick.

CandyMdview

GitHub →

Markdown CLI viewer. Renders to stdout or opens a fullscreen pager. Eight themes, custom JSON themes, OSC 8 toggle.

CandyAnsiInspect

GitHub →

ANSI escape-sequence inspector. Labels SGR / CSI / OSC / DCS / APC / SS3 — feed it stdin, get a human-readable annotation back.

CandySshLauncher

GitHub →

SSH endpoint launcher. YAML / JSON directory of `ssh user@host` shortcuts, interactive picker, pcntl_exec into the chosen ssh.

CandyKv

GitHub →

Personal key/value store CLI — one SQLite file per database. Glob + fuzzy listing, TTL, binary-safe values, JSON/YAML import/export.

CandyMail

GitHub →

Email sending library. SMTP + Resend API transports, attachments, HTML + plain-text multipart, fluent interface.

CandyGitServer

GitHub →

Self-hostable Git server. Smart-HTTP clone/fetch/push via `serve --http`; SSH delegates real git under host-sshd `ForceCommand`; git:// daemon advertisement-only. Users, repos, access control, optional LFS.

CandyTetris

GitHub →

Tetris clone — SRS rules, 7-bag RNG, ghost piece, NES scoring, level-driven gravity. 474 tests / 7262 assertions.

CandyFiles

GitHub →

Dual-pane file manager. Tab-swap focus, multi-select, sort cycling, hidden-file toggle, delete-with-confirm.

CandyCode

GitHub →

TUI AI coding agent. Nine providers (OpenAI, Anthropic, Claude Code, Codex, Gemini, SGLang, Bedrock, Vertex, custom), built-in tools, skills, hooks, sub-agents, MCP, and SQLite session history.

CandyCodeWeb

GitHub →

Browser UI for CandyCode's server mode — a Vite + Vue 3 bundle committed as dist/ and located by a one-class PHP shim, so candy-code serve needs no Node.

CandyVcr

GitHub →

Record + replay sugar-core sessions — JSONL/YAML cassettes, Program::setRecorder(), Player + Byte/Screen assertions, .tape→GIF renderer (themes, GD/imagick, ffmpeg/php), CLI.

CandyGit

GitHub →

Three-pane git TUI — status / branches / log, single-key stage / unstage. Shells out to git for every mutation so your hooks + signing config keep working.

CandySql

GitHub →

Terminal SQL client TUI — list tables, peek at row data, run ad-hoc queries, explore query plans, and monitor server health. Multi-driver: SQLite, MySQL, and PostgreSQL.

CandyCodetime

GitHub →

Privacy-first coding-time tracker — JSONL on disk, SugarCharts-driven dashboard. No cloud, no MongoDB, bring-your-own-storage stays local.

CandyMinesweeper

GitHub →

Minesweeper — customisable board, iterative flood-fill, win/lose detection. Pure-state Board; first-click safety; deterministic-RNG injectable for tests.

CandyGifView

GitHub →

Terminal GIF viewer CLI — sizes to the viewport, plays in the alternate screen (24-bit blocks or luminance ramp) on top of sugar-animation. Antecedent: gifterm.

CandyImage

GitHub →

Terminal image viewer CLI — the chafa-independent front end over sugar-image: protocol auto-detection down a shell-out-free ladder to block and text tiers with colored-character modes, cell sizing, --canvas/--work/--scale dials, GIF animation, and a --dump-detect that answers "why is my image blank?".

CandyTop

GitHub →

Terminal system monitor — cpu, mem + disks, net and process boxes with braille graphs, gradient meters, up to six GPU/NPU boxes, an ipmi BMC band and a VM dashboard, menus, presets, 43 themes and btop-compatible config, over Linux /proc + /sys and FreeBSD collectors.

CandyFlappy

GitHub →

Flappy-Bird in your terminal — bird motion is a SugarSpring projectile, pipes scroll left at a fixed cell rate, collision is per-cell. PRNG-injectable for deterministic tests.

SugarCraft · MIT-licensed · PHP 8.3+

SugarCraft is a PHP-native project. Its original design inspiration came from the Go terminal ecosystem — notably Bubble Tea and the wider Charm family of libraries — reimagined here for PHP 8.3+.
