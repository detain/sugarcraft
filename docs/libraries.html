Forty-two libraries, one ecosystem.

Each library has its own composer package, README, examples, and PHPUnit suite. Pull just the ones you need — or grab the umbrella metapackage and get the lot.

SugarCraft

GitHub →

MVC-style Model–Update–View runtime — Model / Msg / Cmd / Program. Cell-diff renderer saves SSH bandwidth.

SugarStyle

GitHub →

Declarative styling + layout. Style, Border, Table\Table, Listing\ItemList, Tree\Tree, Layout::joinHorizontal/joinVertical, Layout::place, multi-layer Canvas, and Theme.

SugarCellbuffer

GitHub →

Cell-grid value objects — immutable Buffer (2-D cell grid) and Cell (rune/style/link/width). Shared foundation for all rendering, with minimal-repaint diffs via Buffer::diff().

SugarAsync

GitHub →

Shared async vocabulary — CancellationToken, Subscriptions, AsyncOps helpers (withTimeout, withDeadline, cancellable, retry, debounce, throttle, all/race, onPending, singleFlight) + TTL async cache. Dependents: sugar-forms, sugar-vterm, candy-sql, candy-mail, candy-git-server, candy-codetime.

SugarSpring

GitHub →

Damped spring physics + Newtonian projectile sim. The physics behind candy-flappy's bird and the fade/scale/slide animations sugar-widgets drives through it.

SugarMouse

GitHub →

Self-contained Mark/Scan/Get mouse hit-testing + ZoneClickTracker for press/release deduplication, plus the bubblezone-style Zones Manager under SugarCraft\Mouse\Zones.

SugarWidgets

GitHub →

Seventeen components: TextInput, TextArea (dynamic-height), ItemList, Table (per-cell styleFunc), Tree, Viewport, FilePicker, Progress, Spinner, Cursor, Help, Key, Paginator, Scrollbar, Tabs, Stopwatch, Timer.

SugarCharts

GitHub →

Sparkline, Bar, Line, Heatmap, Scatter, TimeSeries, Streamline, Waveline, OHLC, plus Sixel / Kitty / iTerm2 image rendering.

SugarForms

GitHub →

Form library (port of charmbracelet/huh) and foundation for the form primitives SugarWidgets re-exports — Note, Input, Confirm, Select, MultiSelect, Text, FilePicker, multi-page Groups, six themes. Form-level KeyMap override per binding.

SugarMarkdown

GitHub →

Markdown → ANSI renderer. Word-wrap, OSC 8 hyperlinks, syntax highlighting, eight themes, custom themes via JSON.

SugarCli

GitHub →

Terminal UI building blocks — StatusLine, Banner, Section, Stage, HelpText, Frame, Logo, and themes.

SugarSshServer

GitHub →

SSH server middleware framework — Logger, Auth, RateLimit, and a terminal middleware that runs a full SugarCraft app in each session. OpenSSH ForceCommand handles the wire protocol.

SugarMetrics

GitHub →

Telemetry primitives — six instrument kinds (Counter, Gauge, Histogram, UpDownCounter, AsyncCounter, AsyncGauge), five backends (InMemory, JsonStream, StatsD, Prometheus textfile, Multi fan-out), SugarSshServer session middleware; the demo GIF shows the flagship showcase.php example.

SugarLog

GitHub →

Colorful leveled logger. Debug / Info / Warn / Error / Fatal with structured context, Text / JSON / Logfmt formatters, and sub-loggers.

SugarImage

GitHub →

Image-to-cell renderer — Sixel, Kitty, iTerm2, Unicode half-block; Picker facade; ext-gd.

SugarAnimation

GitHub →

ANSI/GIF animation toolkit — ext-gd decode, cell-grid downsample, solid / luminance-ramp presets, .ansi art playback. Viewer CLI: candy-gifview.

SugarVideo

GitHub →

Terminal video player — decodes mp4 (and more) on the fly and renders to ASCII / ANSI / truecolor half-block / sixel / kitty.

SugarColorprofile

GitHub →

Terminal color profile detection + ANSI / ANSI256 / TrueColor conversion. StandardColors and ProfileWriter.

SugarAnsiParser

GitHub →

ANSI escape-sequence parser + state machine (SGR, cursor, erase, DEC modes). Feeds into SugarVterm for cell-grid rendering.

SugarVterm

GitHub →

In-memory virtual terminal emulator. ANSI byte stream → cell grid + cursor + mode state.

SugarPty

GitHub →

Pseudo-terminal primitives for Linux, macOS & Windows (ConPTY) — PtySystemFactory → Contract master/slave: open / spawn / read / write / resize / size, Child lifecycle, SignalForwarder (SIGWINCH → resize).

SugarFocus

GitHub →

Focus-ring state machine — ordered focusable regions with a single focused member + wrap-around Tab/Shift-Tab traversal. Dependency-free.

SugarGallery

GitHub →

Poster grids & rails for media TUIs — a 2-D virtualized, sparse PosterGrid with owner-driven range paging, a Rail carousel, and a renderer-agnostic PosterCard tile.

SugarTreelist

GitHub →

Tree/list view with box-drawing prefixes, cursor navigation, word-wrap, and filter-as-you-type.

SugarConstraints

GitHub →

Constraint-based layout solver — a deterministic greedy solver (GreedySolver) behind a one-method LayoutSolver interface; the deprecated CassowarySolver name delegates to it. Swap solver classes without touching call-sites.

SugarPanels

GitHub →

H/V panels with flex/natural sizing, borders, nesting, and stateful delta rendering.

SugarOverlay

GitHub →

Terminal overlay compositor. Composites Veil overlays with backdrop dimming, z-stack ordering, positioning, and click-outside hit-testing.

SugarNavstack

GitHub →

Navigation breadcrumbs. Mutable NavStack with explicit push/pop, width-aware breadcrumbs, and substring filter.

SugarDashboard

GitHub →

Dashboard TUI library — column grid layout, framed panels, status bar, tabs, and more.

SugarQuickpick

GitHub →

Fuzzy finder overlay. Type to filter a list, arrow keys to select, Enter to confirm. Renders over your app's view string while the background keeps updating.

SugarInput

GitHub →

Terminal escape sequence decoder — legacy keys, Kitty keyboard, SGR/urxvt/X10 mouse, focus, bracketed paste. The missing input layer for PHP TUI.

SugarFuzzy

GitHub →

Fuzzy string matching with scored matched indices — Smith-Waterman + Sahilm algorithms. Extracted from sugar-forms; unblocks filter-highlighting UI.

SugarFlexbox

GitHub →

FlexBox layout engine + simple sort/filter table. Ratio-based sizing, gap, justify, align, per-column styling.

SugarToast

GitHub →

Floating notification overlays. Error / Warning / Info / Success types, configurable position and host-driven auto-dismiss.

SugarDatepicker

GitHub →

DatePicker, Calendar and TimePicker widgets with min/max date constraints, locale-ready day names (English ships today), ANSI rendering; weeks start Monday (firstDayOfWeek is not configurable).

SugarReadline

GitHub →

Interactive prompts — Text, Confirm, Selection, MultiSelect, Textarea. State-machine model, no external readline dependency.

SugarTable

GitHub →

Full-featured interactive data table — column definitions, StyledCell ANSI formatting, pagination, frozen rows and columns.

SugarDiff

GitHub →

Unified-diff engine — LCS line diff, context hunks, GNU diff -u writer and line-number scanner.

Sugar MCP Client

GitHub →

MCP client core — JSON-RPC 2.0 codec, stdio transport with bounded child lifecycle, initialize/tools handshake, tool narrowing.

SugarIgnore

GitHub →

gitignore-style ignore matching over injected file contents — negation, anchoring, nested files, and a backtrack-free matcher that fails closed on hostile patterns.

SugarReleases

GitHub →

Phar self-update engine and launch-time update notice — release selection, sha256 + Ed25519 verification before the swap, one-shot rollback, Windows relaunch-dance.

SugarTesting

GitHub →

Test harness for SugarCraft apps — ProgramSimulator, golden-file assertions, snapshot helpers. Deterministic Model–Update–View testing down to the byte.

SugarCraft · MIT-licensed · PHP 8.3+

SugarCraft is a PHP-native project. Its original design inspiration came from the Go terminal ecosystem — notably Bubble Tea and the wider Charm family of libraries — reimagined here for PHP 8.3+.
