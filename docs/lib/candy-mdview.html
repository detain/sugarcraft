📖 CandyMdview

Markdown CLI viewer + pager

inspired by charmbracelet/glow markdown viewer pager

Composes SugarMarkdown (rendering) and the SugarForms Viewport (scrolling). Render to stdout or open in a fullscreen pager. Twelve built-in themes (ansi, ascii, plain, notty, dark, light, dracula, tokyo-night, pink, solarized, monokai, github) plus custom JSON.

Install

composer require sugarcraft/candy-mdview   # binary lands in vendor/bin/candy-mdview
wget https://github.com/detain/sugarcraft/releases/download/candy-mdview/dev/candy-mdview.phar   # standalone dev phar

Quickstart

vendor/bin/candy-mdview README.md                   # render to stdout (default)
vendor/bin/candy-mdview -p README.md                # open in a fullscreen pager
git log -1 --pretty=%B | vendor/bin/candy-mdview -p # pipe stdin
php candy-mdview.phar README.md                     # the phar takes the same flags
# with vendor/bin (or the phar) on PATH, drop the prefix:
candy-mdview --theme dracula README.md
candy-mdview --width 80 --no-hyperlinks README.md
candy-mdview --theme-config ./my-theme.json README.md

What's in the box

Stdout modecandy-mdview README.md — pipe-friendly, exits clean.
Pager mode-p / --pager — fullscreen scrollable Viewport that reflows live on terminal resize. A header row shows the file, scroll position, and an auto-reload marker. Esc, q, or Ctrl+C to exit.
Theme picker--theme {ansi|ascii|plain|notty|dark|light|dracula|tokyo-night|pink|solarized|monokai|github} (aliases: no, auto-no, tokyonight), --theme-config ./my.json, -s alias for --theme. Three themes (solarized/monokai/github) load from JSON in themes/. With no --theme: ansi on a color-capable terminal, ascii when color is off, plain when the output is undecorated (--no-ansi or a non-terminal without forced decoration).
Word-wrap-w 80 — column width control (1-9999). 0 disables wrapping.
OSC 8 toggleHyperlinks are emitted on terminal output — and into redirected output only when decoration is forced. Labelled links always show the visible text (url) tail; autolinks render the URL itself. --no-hyperlinks strips the OSC 8 envelope.
Stdin supportgit log -1 --pretty=%B | candy-mdview -p — the pager keyboard opens /dev/tty, so piped input stays scrollable.

Exit codes & trust

Exit codes: 0 rendered successfully (an empty file renders blank), 1 runtime failure, 2 usage error — bad theme, unreadable or oversized theme config, missing or unreadable file, a directory argument, non-text (binary) input, a document over 64 MiB, invalid --width, or no input.

Hostile documents render as data. sugar-markdown strips escape, control, and OSC bytes on output, per element (sanitization is default-on and this tool never opts out), so a document cannot move the cursor or restyle the stream. OSC 8 URLs face a refused-scheme denylist: javascript:, data:, and vbscript: never reach a clickable envelope; other schemes pass to the terminal's opener unfiltered. Usage errors go to stderr with argv paths and option values sanitized before display, and the rendered document is written raw — the output formatter never interprets <tags> inside your Markdown.
