🍬 SugarConstraints

Constraint-based layout solver for terminal grids

inspired by ratatui/ratatui layout constraint-solver dock-layout

A ratatui-style constraint layout solver behind a one-method LayoutSolver interface: GreedySolver (deterministic greedy solver, extracted from sugar-style, which now delegates back through its Layout\Solver bridge) implements every constraint type, and the deprecated CassowarySolver shim delegates to it. Plus DockLayout, a center-plus-side-stacks pane geometry. Consumers: sugar-panels (compat mode), candy-code (the Dock\* surface), candy-sql (dashboard page); sugar-forms requires the package but its withConstraints() knob is dormant, and sugar-widgets does not consume it.

Install

composer require sugarcraft/sugar-constraints

Quickstart

use SugarCraft\Constraints\Constraint\Constraint;
use SugarCraft\Constraints\{Direction, GreedySolver, Region};

$solver = GreedySolver::new();
$region = Region::fromSize(100, 24);

// The widths in the comments are what this 100-cell split returns.
$rects = $solver->solve($region, Direction::Horizontal, [
    Constraint::length(20),       // 20: exactly 20 cells
    Constraint::min(10),          // 10: a floor; the Fills below take the slack
    Constraint::percentage(25),   // 25: 25% of 100
    Constraint::ratio(1, 10),     // 10: 1/10 of 100
    Constraint::fill(1),          // 12: a third of the 35 cells left (+1 rounding cell, first Fill)
    Constraint::fill(2),          // 23: two thirds of them
]);

// Max is a greedy ceiling: it grows into free space up to its cap.
$capped = $solver->solve($region, Direction::Horizontal, [
    Constraint::length(20),       // 20
    Constraint::max(15),          // 15: clamped at its ceiling
    Constraint::fill(1),          // 65: everything Max did not take
]);

Solvers

GreedySolverDeterministic greedy solver. Extracted from sugar-style, which routes its own splits back through this solver. No deps; no strength or priority vocabulary. Small and stateless. Lossless rounding: floored fractions are handed back so for a well-constrained set the regions tile the span (Fill/Max remainder to the first Fill (or the first Max when no Fill is present), Min slack residue to the first Min, a Percentage/Ratio shortfall of at most N−1 cells reclaimed earliest-first). When fixed demand exceeds the span, regions shrink proportionally and still sum to it — withoutOverflowTruncation() keeps full base sizes instead. Tiling assumes a positive-weight recipient: under-constrained fixed-only sets keep their gap, and a zero-weight-only Fill set leaves slack too — the README names all four carve-outs.
CassowarySolver (deprecated)The original Big-M simplex prototype never converged, so solve() raises E_USER_DEPRECATED and delegates wholly to GreedySolver — results are identical. Kept only so existing call-sites keep working.
DockLayoutCenter pane plus left/right weighted slot stacks. Stack heights are split in exact integer arithmetic (no float decides a boundary row); a weight set whose scaled sum would overflow is refused with InvalidArgumentException where it is introduced, and resolve() itself never throws, degrading by dropping a side on small frames.

Constraint types

LengthFixed cell count — n cells, except the documented carve-outs (the reclaim ladder inflates it in sets with no Min and no Fill, overflow truncation shrinks it, compat mode runs off-grid); the README walks them.
MinSoft floor — at least n cells while slack survives every Fill and Max; clamps proportionally when demand exceeds the span; the README documents the semantics.
MaxCeiling — greedy, clamped to n cells.
FillProportional remainder — weight controls distribution across multiple Fill constraints.
PercentageFraction of total — n% of the available dimension.
RatioFractional proportion — num/denom of the total span, reserved like a fixed size.

Use it for

  • Extracted from sugar-style — sugar-style's Layout\Solver bridge now delegates back through this package.
  • Live pane splits — sugar-panels (compat mode), candy-code's Dock\* surface, and the candy-sql dashboard; sugar-forms requires it but its constraint knob is dormant, and sugar-widgets does not consume it.
  • Swap solver without breaking call-sites — LayoutSolver (solve() alone; construction lives on the concrete classes) is the only public contract.
