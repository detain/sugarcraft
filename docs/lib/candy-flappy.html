🐦 CandyFlappy

Flappy-Bird in your terminal

inspired by kbrgl/flapioca tui game flappy flapioca sugar-spring physics sugarcraft

Physics-driven flap game — the bird's vertical motion is a SugarSpring projectile (gravity + an upward velocity kick on each tap), pipes scroll left at a fixed cell rate, collision is per-cell. Pure-state Game class; the renderer is a one-pass canvas fill.

Install

Pre-1.0 the package publishes a dev branch only, so pull it in explicitly as :@dev:

composer require sugarcraft/candy-flappy:@dev

Quickstart

# Monorepo clone — per-lib install, then the checked-in bin:
cd candy-flappy && composer install && ./bin/candy-flappy

# Composer install — the vendored console bin:
vendor/bin/candy-flappy

# Or download the standalone .phar release from GitHub and run it with php.
// Programmatic:
use SugarCraft\Core\Program;
use SugarCraft\Core\ProgramOptions;
use SugarCraft\Flappy\Game;

(new Program(Game::start(),
             new ProgramOptions(useAltScreen: true)))->run();

What's in the box

Real physicsBird movement is a Projectile with gravity vector. flap() rebuilds the projectile with an upward velocity kick — same trick the original flapioca uses, just expressed as projectile state.
Pipe spawningA new pipe pair every PIPE_EVERY ticks; the gap row is sampled from the injected PRNG so tests pin layouts deterministically.
Tick-drivenGame::subscriptions() arms Subscriptions::withTick('game-tick', Game::TICK_SECONDS) — TICK_SECONDS is 1/Bird::TICKS_PER_SEC, exactly 1/30 s. Each tick advances physics, scrolls pipes and checks collision; the subscription goes empty on crash, on a too-small viewport, and under the NoTty refusal posture.
Per-cell collisionBird's row is rounded to a cell index; collision = bird column matches a pipe column AND the row is outside the open gap.
Ready cardThe board opens frozen; the first flap starts the run. r reseeds (mid-flight too); q / Esc / Ctrl+C quit — a qualifying mid-flight score is settled before the process exits.
Score on passEvery tick that moves a pipe past the bird's column bumps the score.
Variable difficultyPipe gap shrinks from 6 cells down to 3 as score increases — every 5 points the gap narrows by 1 cell, making the game progressively harder.
