SugarLog is a leveled, colorful logger for PHP 8.3+ command-line tools. It writes Debug, Info, Warn, Error and Fatal records with structured key/value context, renders them as text, JSON or logfmt, and creates sub-loggers that carry persistent fields. The record model is inspired by charmbracelet/log (Go); the port is native PHP, not a binding.

Install

composer require sugarcraft/sugar-log

Requires PHP 8.3 or newer and psr/log ^3.0. The package requires its sugarcraft/ siblings at dev-master, so a project on the default stable minimum stability must add "minimum-stability": "dev" and "prefer-stable": true to its root composer.json.

Quickstart

use SugarCraft\Log\Logger;
use SugarCraft\Log\Level;

$log = Logger::new(level: Level::Debug);   // default threshold is Info; Debug opts in
$log->debug('preheat cycle', ['stage' => 1]);
$log->info('Starting oven', ['degree' => 375]);
$log->warn('Almost ready', ['batch' => 2]);
$log->error('Temperature too low', ['err' => 'underheated']);

$child = $log->with(['service' => 'bakery']);   // every line from $child carries service=bakery
$child->info('Batch complete');

Concepts and how it works

Levels. Level is an int-backed enum: Debug is -4, Info 0, Warn 4, Error 8 and Fatal 12. The values follow charmbracelet/log's deltas and are not RFC 5424 severities, so compare ->value when filtering. A record is emitted when its level value is at or above the logger's minimum level, which defaults to Info. print() and printf() bypass that filter.

Pipeline. Logger builds one record per call, hands it to a Formatter (TextFormatter unless you pass another), and writes the rendered line to the configured stream. Records at or above the error threshold go to the optional error stream instead. Fatal records are written first and then raise FatalLoggedException, a RuntimeException subclass.

Color is decided twice. The constructor consults the color-profile probe once, and a per-write gate (ColorGate::allowsColor()) keeps files and pipes free of ANSI bytes. Styles are snapshotted per logger, so changing one logger's styles does not recolor another.

Immutable children, mutable setters. with*() methods such as withPrefix() and with() return a new logger and leave the parent alone. set*() methods such as setPrefix() change the logger in place. The formatter and the minimum level have one spelling each, withFormatter() and withMinLevel().

Tasks and recipes

Write JSON lines to a file

use SugarCraft\Log\Logger;
use SugarCraft\Log\Formatter\JsonFormatter;

$file = fopen('/var/log/bakery.jsonl', 'a');
$log  = Logger::new(formatter: new JsonFormatter(), stream: $file);
$log->info('batch complete', ['loaves' => 12]);

A stream that is a file or a pipe receives plain bytes, so the JSON lines carry no escape sequences.

Route errors to stderr

use SugarCraft\Log\Logger;
use SugarCraft\Log\Level;

$log = Logger::new(errorStream: STDERR, errorStreamAt: Level::Error);
$log->info('still on stdout');
$log->error('goes to stderr');

Catch the fatal signal

use SugarCraft\Log\FatalLoggedException;
use SugarCraft\Log\Logger;

$log = Logger::new();
try {
    $log->fatal('out of flour');   // the record is written, then the exception is thrown
} catch (FatalLoggedException $e) {
    exit(1);
}

Forward PSR-3 calls and run hooks

use SugarCraft\Log\Logger;
use SugarCraft\Log\PsrBridge;
use SugarCraft\Log\Hook\HookRegistry;
use SugarCraft\Log\Level;

$hooks = new HookRegistry();
$hooks->onLevel(Level::Error, static function (Level $level, string $psr, string $msg, array $ctx): void {
    // page the on-call engineer, post to a chat channel, and so on
});

$psr = new PsrBridge(Logger::new(), $hooks);
$psr->error('oven door open', ['zone' => 2]);

Hooks fire only through PsrBridge or an explicit HookRegistry::fire(). Direct Logger calls never dispatch hooks.

Add caller location

use SugarCraft\Log\Logger;

$log = Logger::new(reportCaller: true);
$log->info('where am I');

The caller is the nearest frame outside the library, found by a bounded walk of at most 20 frames. When no such frame exists, the caller part is omitted rather than guessed.

Styling and theming

Each logger owns a Styles instance. Its public arrays levels, keys and values map a level, a generic key role, or an individual field name to a style, and its timestamp, prefix, caller and message properties style the other parts. Set padLevelText to true to pad level labels to a common width. Use keyStyle() to read the style for one field.

use SugarCraft\Log\Logger;
use SugarCraft\Log\Styles;

$styles = Styles::snapshot();   // an independent copy; shared() is the shared instance
$styles->padLevelText = true;
$log = Logger::new();
$log->setStyles($styles);

Color is chosen at construction by the color-profile probe, where NO_COLOR is honored. CLICOLOR_FORCE and FORCE_COLOR outrank NO_COLOR there. A non-terminal destination still receives plain bytes on every write, and CLICOLOR_FORCE reaches that per-write gate when it is set to any non-empty value other than 0.

Examples

  • examples/demo.php runs every level, the structured fields, sub-loggers, the JSON and logfmt formatters, and the stdlog adapter in one run.
  • examples/panic-handler.php installs Log::installPanicHandler() and then triggers a fatal error so the styled panic report is visible.

Testing

Run the suite from the package root with vendor/bin/phpunit. The tests cover the logger, each formatter, the record-integrity rules, the PSR-3 bridge, the hook registry, the stdlog adapter, the panic formatter and the locale catalogs. ReadmeSnippetsTest lints and runs every fenced PHP block in the README, so a documented snippet that drifts from the API fails the suite.

Troubleshooting and FAQ

Debug lines never appear

The default threshold is Level::Info. Pass level: Level::Debug to Logger::new(), or derive a child with withMinLevel(Level::Debug). The shared logger behind the Log facade is changed with Log::setLogger(Log::logger()->withMinLevel(Level::Debug)).

Colors appear in a log file, or never appear in a terminal

Files and pipes receive plain bytes by design. The per-write gate turns color on for a non-terminal destination only when CLICOLOR_FORCE is set to any non-empty value other than 0, such as 1 or true. NO_COLOR is read once, when the logger is constructed. Exporting it later does not change a logger that already exists.

Hooks never run for a direct logger call

HookRegistry callbacks are dispatched only by PsrBridge or by an explicit fire(). Log through a PsrBridge built with the registry, or call fire() yourself.

A script stops after fatal()

This is intended. The record is written first, then FatalLoggedException is thrown. Catch it at the entry point, as in the fatal recipe above, if the script should exit cleanly with a status code.

A context field is written as ctx_something

The record keys level, msg, time, caller, prefix and _encode_error are reserved. A context field that uses one of those names, or a name already claimed earlier in the same record, is written with a ctx_ prefix so it cannot overwrite the record's own parts. Rename the field to avoid the prefix.

reportCaller shows no file and line

Caller detection is best effort. It walks at most 20 frames and omits the caller part when no frame outside the library is found within that bound.
