SugarLog

Colorful leveled logger

inspired by charmbracelet/log loggingclioutput

Minimal, colorful leveled logging. Debug / Info / Warn / Error / Fatal with structured key/value context, Text / JSON / Logfmt formatters, and sub-loggers with persistent fields.

Install

composer require sugarcraft/sugar-log

Quickstart

use SugarCraft\Log\Logger;

$log = Logger::new();
$log->info('Starting oven', ['degree' => 375]);
$log->warn('Almost ready', ['batch' => 2]);
$log->error('Temperature too low', ['err' => 'underheated']);

$child = $log->with(['service' => 'bakery']);   // every line from $child carries service=bakery
$child->info('Batch complete');

What's in the box

Leveled loggingDebug, Info, Warn, Error, Fatal. Color runs in two layers: a construction-time style profile that honors NO_COLOR / CLICOLOR_FORCE, and a per-write gate that downgrades non-TTY destinations so files and pipes get plain bytes.
Three formattersTextFormatter (default), JsonFormatter, LogfmtFormatter — swap via withFormatter().
Structured contextArbitrary key/value pairs attached to every log call.
Sub-loggerswith(array $fields) creates a child logger that inherits all context.
StandardLogAdapterGo-style print()/printLn()/fatal()/panic() call pattern over a sugar-log Logger — a shape, not an interface (implements no contract); for PSR-3 interoperability use PsrBridge.
PSR-3 bridgePsrBridge wraps a Logger and exposes the full PSR-3 LoggerInterface API.
Hook systemRegister per-level callbacks via HookRegistry::onLevel() for middleware-style interceptors — dispatched only by PsrBridge (or an explicit fire()); direct Logger calls never fire hooks.
Caller inforeportCaller on Logger adds basename:line of the nearest caller outside the library — best-effort: a bounded 20-frame walk, and the part is omitted when no such caller is found.
PartsOrder DTOConfigure which log-parts appear and in what order — default, syslog, or custom.
