Build dashboard-style terminal UIs with a column grid, constraint layout, ratio grid, data grid, tree views, modals, status bars, tabs, and plot/canvas rendering. Compose complex layouts from reusable components, and extend the whole system through the module/plugin layer. All motion is frame-driven — the library renders synchronously and the host supplies every frame, so a reduced-motion presentation is always reachable by holding the frames still.

Install

composer require sugarcraft/sugar-dashboard

Quickstart

use SugarCraft\Dashboard\Layout\Grid\{StackedGrid, Options, ItemOptions};
use SugarCraft\Dashboard\Components\Card\{Card, Text};

$grid = new StackedGrid(new Options(fitScreen: true));
$grid->addItem(Card::titled(Text::new('CPU 42%'), 'Load'), new ItemOptions(column: 0));
$grid->addItem(Card::titled(Text::new('3 alerts'), 'Alerts'), new ItemOptions(column: 1, expandVertical: true));

$grid->setSize(100, 24);
echo $grid->render();   // two bordered cards side by side; below 90 columns they stack

What's in the box

StackedGridColumn grid that splits width evenly (floor(width ÷ columns) per column) and stacks when narrow — gap and percentage sizing live in GridLayout.
FrameFramed panel with border, title, and padding.
StatusBarStatus bar component for dashboard footers.
TabsTabbed interface for switching between views.
Card / Paragraph / TextReusable UI components for building panels.
Event systemKeyboard, mouse, focus, and resize event handling.
DualSampleGraphbtop's history graph: two samples per cell quantized through the 5×5 graph_symbols table, in braille / block / block2 / tty families, with invert, no-zero, max-value scaling, gradient colouring and the graph_bg underlay.
Position-coloured MeterMeter::withGradient($stops, positionWise: true) renders btop's one-row ■ bar — each cell coloured at its own position on a 101-stop ramp, meter_bg tail, invert, memoized per shape.
GradientsGradient101::expand() (btop's integer ramp law), GradientStore named ramps (at('cpu', 73)), and value-driven BrailleCanvas::withGradient().
NetAutoScalebtop's network-graph ceiling hysteresis: grows or shrinks only after 5 sustained samples, 10 KiB floor, optional shared (sync) ceiling.
Process rowsProcRowComposer renders a btop process-list row (pid … mem, 5×1 cpu mini-graph on graph_bg, cpu%) with DistanceFade shading; ProcGraphTracker manages per-pid graphs.

btop-style graphs & meters

Ported from aristocratos/btop for candy-top; colour and quantization laws are byte-faithful to btop. Run php examples/dual-sample-graph.php for every family.

use SugarCraft\Core\Util\Color;
use SugarCraft\Dashboard\Plot\Braille\DualSampleGraph;
use SugarCraft\Dashboard\Plot\Chart\Meter;

$stops = [Color::hex('#80d0a3'), Color::hex('#dcd179'), Color::hex('#d45454')];

echo DualSampleGraph::new(12, 3)
    ->withGradient($stops)
    ->withData(5, 12, 30, 55, 80, 95, 70, 45, 20, 10, 35, 60)
    ->render(), "\n";

echo Meter::new(0.62)->withWidth(20)->withGradient($stops, positionWise: true)->render(), "\n";
