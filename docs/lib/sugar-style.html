✨ SugarStyle

Declarative styling + layout

inspired by charmbracelet/lipgloss styling layout borders tables trees

Style, Border, Table\Table, Listing\ItemList, Tree\Tree, Layout::joinHorizontal/joinVertical, Layout::place, multi-layer Canvas, and Theme — the canonical colour palette for all SugarCraft libs. The rendering core is pure — no I/O (an optional Output facade wraps print/printf/fprint) — so you can render frames inside a unit test.

Install

composer require sugarcraft/sugar-style

Quickstart

use SugarCraft\Style\{Style, Border, Layout, Position};
use SugarCraft\Style\Table\Table;
use SugarCraft\Core\Util\Color;

$banner = Style::new()
    ->bold()
    ->foreground(Color::hex('#ff5f87'))
    ->padding(0, 2)
    ->render('hello, styled world');

$table = Table::new()
    ->headers('Name', 'Age')
    ->row('Alice', '30')
    ->row('Bob', '25')
    ->border(Border::rounded())
    ->render();

echo Layout::joinVertical(Position::LEFT, $banner, $table);

What's in the box

StyleForeground / background, bold / italic / underline, overline, padding, margin, width, alignment. Immutable value object; setters keep lipgloss's bare names (fg(), bold(), width()) and each returns a new Style.
BorderEight built-in styles + custom. Border::rounded(), thick(), double(), block(), hidden(), normal(), ascii(), markdownBorder().
TableHeaders, rows, per-cell styleFunc. ANSI-aware width calc with grapheme cluster support. Optional wrap() callback: every line it returns renders, so a wrapped row spans several physical lines.
List + TreeBulleted lists and ASCII trees with custom enumerators.
LayoutjoinHorizontal, joinVertical, place, plus the ratatui-style constraint solver (Layout\Layout::vertical([...])->split()) and RegionBridge for handing rectangles between sugar-constraints and sugar-cellbuffer.
CanvasMulti-layer compositor. Z-ordered overlays merged by a cell-aware row splice (no alpha blending — upper cells replace lower ones), ideal for modals + tooltips.
ThemeSingle source of truth (SSOT) colour palette. 10 named factories (dark/light/dracula/tokyoNight/oneDark/githubDark/solarized*/ansi/adaptive). 13 colour slots (foreground/background/primary/secondary/accent/muted/error/warning/success/info/border/separator/cursor). All with*() setters return a new Theme. adaptive() reads $COLORFGBG: any numeric slot (0-255) in the last field decides light vs dark by luminance (e.g. 7/15 light, 0/8 dark); unset, non-numeric or out-of-range falls back to dark.
Embedded titles + seamsbtop-style box titles: Border::withEmbeddedTitle() brackets text in junctions (╭─┐cpu┌────┐12:00┌───────╮) on any of six anchors; Border::seam() picks the ┬ ┴ ├ ┤ ┼ rune where an internal divider meets the frame, preserving the border family.
Colour degradationA Style carries a ColorProfile and render() downsamples to it, as charmbracelet/colorprofile's Writer does: TrueColor → 38;2, Ansi256 → 38;5, Ansi → 30..37/90..97, Ascii (what NO_COLOR selects) drops colour but keeps bold/italic/underline and OSC 8 links, and NoTty strips every escape — including ones carried in by pre-styled content, a transform() or a border title — while padding, borders and alignment stay. Tier rewrites apply to RGB colours; palette-slot colours (Color::ansi(n)) always emit their 30..37/90..97 form at every tier.
Underline truthSub-style shapes ride the numeric SGR 4:N form emitted only alongside underline() — terminals that ignore 4:N typically draw no underline at all (no plain SGR 4 companion is sent). SGR 58 has no 4-bit spelling, so at the Ansi tier the underline colour is applied through the foreground attribute instead — it recolours the glyphs rather than tinting the rule.

Embedded border titles

use SugarCraft\Style\Border;
use SugarCraft\Style\Border\TitleAnchor;
use SugarCraft\Style\Style;

$border = Border::rounded()
    ->withEmbeddedTitle('cpu')
    ->withEmbeddedTitle('12:00', TitleAnchor::TopCenter)
    ->withEmbeddedTitle('mem', TitleAnchor::BottomLeft)
    ->withEmbeddedTitle('disk', TitleAnchor::BottomLeft);

echo Style::new()->border($border)->width(24)->render('load 0.42');
// ╭─┐cpu┌────┐12:00┌───────╮
// │load 0.42               │
// ╰─┘mem└─┘disk└───────────╯

echo Border::normal()->seam(left: true, right: true, up: false, down: true); // ┬
