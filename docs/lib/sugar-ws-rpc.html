SugarWsRpc

WebSocket RPC transport — skeleton, no API yet

first-party websocket rpc skeleton

The WebSocket transport that a SugarCraft host uses to exchange request and response messages with a remote peer, and to receive server-pushed frames on the same connection. This library is a skeleton: its namespace and packaging exist, and the transport classes arrive in a later change. There is no Charmbracelet upstream; this library is first-party.

Install

composer require sugarcraft/sugar-ws-rpc

Requires PHP 8.3 or newer. The package has no runtime dependencies beyond PHP.

Status

The package currently ships only its PSR-4 wiring under SugarCraft\WsRpc\. No public API exists yet, so there is no quickstart to show. The channel bundles keep their own serve-bridge socket code until the transport lands here.
