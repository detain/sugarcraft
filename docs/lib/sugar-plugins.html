The generic plugin core for SugarCraft hosts. It holds the contracts a plugin and a channel implement, the immutable context a plugin starts with, the escape that fences dynamic bytes out of a model prompt, and the mechanics a host would otherwise copy: a trust-gated loader, a quarantine ledger, a registry and a manifest reader. It has no host policy: discovery roots, trust settings and stores stay with the host, which requires this package and never the reverse. First-party: original work, with no upstream Go port.

Install

composer require sugarcraft/sugar-plugins

Quickstart

use SugarCraft\Plugins\Manifest\PluginManifest;
use SugarCraft\Plugins\Support\PromptFence;

$manifest = PluginManifest::fromDir('/home/me/.candy-code/plugins/weather');
if ($manifest !== null) {
    $contract = $manifest->contract(); // the integer host contract, or null
    $entries = $manifest->entrypoints(); // realpaths contained by the plugin directory
}

$safe = PromptFence::escape($untrustedText); // escape before the bytes reach a model prompt

The laws

Contracts, not policyThe library holds the interfaces and the generic mechanics. A host keeps the discovery roots, the trust list contents and its own stores, so a second host reuses the same core without inheriting one host's rules.
Trust before loadA plugin loads only when its name is on the trust list, and only from entrypoints its manifest names. An entrypoint path first seen on one launch is listed and loads on the next, so a new entrypoint under a trusted name cannot run silently. A rewrite of a path already seen is not listed, so it loads without a quarantine stop. An in-place rewrite by another account needs group write on the file itself. A replace-by-rename by another account is refused as a foreign owner when a uid is known (an explicit processUid, or ext-posix), and loads only when none is, from a directory another account can write (group-writable, or owned by that account). A rewrite by the file's own account loads everywhere. That gap is open.
One fence rosterEvery splice of dynamic text into a model prompt goes through PromptFence::escape(), which escapes against a single tag roster. A second local regex would open a forgery window.
Immutable contextA plugin receives a read-only PluginContext with its name, the project root, the loop, a log closure, its frozen settings and its state directory. Nothing in it is writable by the plugin.

Use it for

  • Writing a plugin — implement Plugin, or a channel that adds one of the capability interfaces, and read the translation base Lang for its own catalog.
  • Building a host — load candidates through PluginLoader, keep trust and quarantine in JsonFileQuarantineLedger, and register them in PluginRegistry.

Plugin interface

One plugin in its lifecycle shape: the host loads it under its trust gate, registers it by name, starts it with a PluginContext, and disposes it at shutdown.
