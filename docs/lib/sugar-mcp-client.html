A Model Context Protocol client core the whole ecosystem can share: JSON-RPC 2.0 envelopes, a newline-framed stdio transport with a bounded child lifecycle, the initialize/tools handshake, and deny-before-allow server narrowing — tool rosters follow servers. Here "client" means the tool-CALLING side: this library spawns and drives an MCP server child process; it does not host one. It was extracted from candy-code's MCP stack, so every surface that talks to an MCP server over stdio shares the same framing and the same handshake-and-deadline rules. First-party: MCP is a specification, not a Go port.

Install

composer require sugarcraft/sugar-mcp-client

Requires PHP 8.3 or newer. The only runtime dependency beyond PHP is sugarcraft/sugar-core, which supplies the output sanitizer used below.

Suggested: ext-posix. It drives the liveness probes for server children, lock owners and forked successors. Without it, the lock-owner probe falls back to Linux /proc, which can still certify a dead pid as absent; only a host with neither posix nor procfs leaves that probe failing open as alive. A forked successor's server-liveness check has no such fallback: without ext-posix it assumes the server is up, so a dead server surfaces through the pipes (a write failure or EOF) rather than through the probe.

Quickstart

use SugarCraft\Core\Util\Sanitize;
use SugarCraft\McpClient\StdioMcpServer;

$server = new StdioMcpServer(
    name: 'everything',
    command: 'npx',
    args: ['-y', '@modelcontextprotocol/server-everything'],
);

$server->start();              // initialize → notifications/initialized → tools/list, one 60 s clock
foreach ($server->listTools() as $tool) {
    echo $tool->name, ' — ', Sanitize::untrusted($tool->description), PHP_EOL;  // server-authored prose
}

$result = $server->callTool('echo', ['message' => 'hi']);
// normally ['content' => [['type' => 'text', 'text' => '…']]], or ['error' => …]
// naming the CAUSE: a failed call never throws and never answers bare.

$server->stop();               // closes the pipes, then TERM → KILL → reap; __destruct calls stop() if you forget

The example spawns npx -y @modelcontextprotocol/server-everything, so it needs Node.js on PATH. Any stdio MCP server takes the same three arguments: a name, a command and an argv list. For a trial with nothing to install, run php examples/echo.php (see Examples).

Concepts

The library is the client half of MCP. It launches a server as a child process, speaks newline-delimited JSON-RPC 2.0 over the child's stdin and stdout, and runs the handshake: initialize, then notifications/initialized, then tools/list. The handshake runs under a single monotonic deadline, so a slow start cannot stretch it leg by leg.

Failures are answers, not exceptions. callTool(), listResources() and the other convenience methods return either the result payload or ['error' => 'why']. A handshake that cannot complete is different: start() stops the child and throws, with any captured stderr attached.

Launching a configured stdio entry runs third-party code as the invoking user, and the child inherits the full parent environment unless you narrow it. Read the trust boundary before you configure a server.

Tasks

Use it for

  • Speaking MCP from any PHP process: spawn a stdio server child, handshake, list and call tools, with the framing and timeout rules already in place.
  • Agent tool surfaces: narrow which servers each agent may see with globs and deny-before-allow. Tool rosters follow servers, which is the same semantics candy-code builds on.
  • Bounded subprocess I/O: the transport is a reference for newline-framed JSON-RPC over pipes, with deadlock-free pumping and bounded child teardown (TERM → KILL → reap on stop() and on destruct). A process SIGKILLed mid-use leaves its child to the embedding process manager.

Narrow which servers an agent sees

McpRouter takes the servers keyed by config name and a deny list. A deny pattern always wins over an allow entry. An empty allow list means allow all, minus the denied servers.

use SugarCraft\McpClient\McpRouter;

$router  = new McpRouter(['filesystem' => $fs, 'git' => $git], ['git']);  // deny 'git'
$servers = $router->resolveAllowedServers(['filesystem', 'git']); // only 'filesystem' survives
$tools   = $router->resolveAllowedTools(['filesystem']);          // tools of the surviving servers

Bound one tool call

A call has no deadline unless you pass one. A bounded call answers with an error when the deadline passes, and the connection stays usable.

$result = $server->callTool(
    name: 'slow-report',
    arguments: ['days' => 30],
    timeoutSeconds: 30.0,        // zero and negative values are refused at the door
);
// on timeout: ['error' => 'Tool call timed out after 30s and was cancelled; …']

Read a failure

$result = $server->callTool('echo', ['message' => 'hi']);

if (isset($result['error'])) {
    fwrite(STDERR, Sanitize::untrusted((string) $result['error']) . PHP_EOL);
    exit(1);
}
foreach ($result['content'] ?? [] as $block) {
    echo Sanitize::untrusted((string) ($block['text'] ?? '')), PHP_EOL;
}

Keep the child's environment small

The child inherits the full parent environment by default. envRemove: drops named variables from that inheritance, and curatedEnv: replaces the environment outright. spawnPlanner: gives full control over the argv and the env that actually spawn.

$server = new StdioMcpServer(
    name: 'narrow',
    command: 'npx',
    args: ['-y', '@modelcontextprotocol/server-everything'],
    envRemove: ['AWS_SECRET_ACCESS_KEY', 'SSH_AUTH_SOCK'],
);

// Or replace the environment wholesale. curatedEnv: cannot be combined with env:,
// envRemove: or spawnPlanner:, and the constructor throws if you try.
$server = new StdioMcpServer(
    name: 'curated',
    command: 'npx',
    args: ['-y', '@modelcontextprotocol/server-everything'],
    curatedEnv: ['PATH' => '/usr/local/bin:/usr/bin:/bin'],
);

Architecture

The wire layers sit under StdioMcpServer. JsonLines\Reader turns raw pipe chunks into complete lines and caps how large one line may grow. McpMessage and the Protocol classes build and read the envelopes. ExchangeLock serializes exchanges when forked processes share one connection.

McpMessageJSON-RPC 2.0 envelope: parse() / request() / notification() / success() / error(); a resultSet sentinel keeps explicit "result": null representable; toJson() is the wire and fails closed on unencodable payloads, toArray() is inspection.
McpTool / McpServerOne tool definition value object with a well-typedness gate that refuses malformed server output — control bytes in names are rejected at parse; descriptions are free-form prose that passes through verbatim, so display them through sugar-core Sanitize::untrusted — plus the McpServer interface: lifecycle, tool surface, and the shared raw legs request()/notify().
StdioMcpServerargv-array proc_open child, newline-delimited (NDJSON) framing, 64 KiB rolling stderr tail absorbed on every wait set, one monotonic (hrtime) deadline across the whole handshake, protocol-version negotiation, and a per-second handshake beat via start(onWait:).
ExchangeLockSerializes whole request/response exchanges when forked processes share one stdio connection; records a W/R phase so the next holder resynchronizes after a killed one; the file is created at mode 0600, verified before any payload, and a filesystem that refuses the mode fails the open loudly.
Protocol codecThe candy-code.v1 JSON-RPC 2.0 codec: JsonRpc decodes one client message into a Request and builds the four wire shapes; RpcError carries an ErrorCode, a kind and data. Undecodable text is answered with an RpcError, never null.
McpRouterDeny-before-allow SERVER narrowing over any set of McpServer instances — tool rosters arrive whole, so rosters follow servers; fnmatch globs; empty allowlist means allow-all; malformed entries fail loud.
Server requests & trustA server's own requests (ping, roots/list, elicitation/create) are answered inline while a call is in flight — default ping acknowledged, anything else refused "Method not found" — with the handler's wall clock excluded from the call's budget. Running a configured stdio entry executes third-party code as the invoking user with the FULL parent environment: see the README's Trust boundary.

Examples

examples/echo.php is a self-contained round trip. Run plainly, the file is the client: it starts itself as a server, runs initialize, tools/list and tools/call, and prints the exchange. Run with --serve, it is the stdio server. It needs no Node.js, no download and no network.

php examples/echo.php
server: example-echo 1.0.0
tool: echo - Echoes the message argument back as text
reply: echo: dependency-free round trip
OK

The suite runs this example headless (ExamplesTest), so the promise cannot rot.

Testing

cd sugar-mcp-client && composer install && vendor/bin/phpunit

The fixture servers under tests/Fixtures are PHP scripts that misbehave on purpose: they send oversized frames, stall, fork, write noise to stdout, or answer the handshake wrongly. The suite checks that the client refuses each of them with a named cause, so it needs no Node.js.

Troubleshooting and FAQ

start() throws after 60 seconds

The handshake deadline is 60 seconds by default, sized for a cold npx fetch. Raise startTimeoutSeconds: for a slow start. The exception carries the captured stderr, so the cause is usually in the message.

A tool shows up with escape codes or fails to list

Descriptions are server-authored prose. The transport does not scrub them, so pass every name and description through Sanitize::untrusted() before it reaches a terminal. A definition whose name carries control bytes is skipped. malformedToolDefinitions() lists what was skipped during the last start(), and malformedToolDefinitionsReport() gives a one-line summary.

foreach ($server->malformedToolDefinitions() as $label) {
    error_log("skipped MCP tool definition: {$label}");
}

A call returns ['error' => …] instead of throwing

This is by design. A failed call never throws, so check for the error key, as the task above shows. The payload names the cause: the server's JSON-RPC code and message, a dead child, or a refused frame.

A forked worker blocks on another worker's call

Each connection has one ExchangeLock, so exchanges serialize by design. Give each worker its own server if it needs to call in parallel. If start() fails with a lock error, check that lockDir: exists and that the filesystem accepts mode 0600.

The child sees my secrets

It inherits the full parent environment by default. Use envRemove: to drop named variables, or curatedEnv: to replace the environment entirely.
