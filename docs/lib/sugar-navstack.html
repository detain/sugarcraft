SugarNavstack

Navigation breadcrumbs for terminal UIs

inspired by KevM/bubbleo navigationbreadcrumbrouting

Push / pop navigation items to build breadcrumbs. Track a stack of visited locations — useful for file explorers, menu trees, and cwd-tracked directory trails. Rendered trails carry click zones (sugar-mouse) and an accessible HTML shape (aria-label nav + aria-current).

Install

composer require sugarcraft/sugar-navstack

Packagist currently serves this package from dev-master only (no tagged release yet): require it with a root minimum-stability: "dev" plus an exact sugarcraft/sugar-navstack: "dev-master".

Quickstart

use SugarCraft\NavStack\NavStack;

// NavStack is a mutable stack: push() returns the same stack for chaining.
$nav = NavStack::new()
    ->push('Home', '/')                    // title, then any payload
    ->push('Settings', '/settings')
    ->push('Display', '/settings/display');

echo $nav->view();          // Home › Settings › Display
echo $nav->view(' / ');     // Home / Settings / Display

$top = $nav->pop();         // NavigationItem: title 'Display', data '/settings/display'
$nav->depth();              // 2

What's in the box

NavStackPush / pop navigation stack (mutable, chainable push) with depth, parent and truncation helpers.
Directory stacks (Shell)Explicit cwd-tracked trails — your host detects a directory change and calls pushDirectory(); nothing auto-pushes, and `.`/`..` follow the documented no-downward-walk rule.
FilterASCII case-folded substring filtering over titles and payload data (arrays matched by value up to 64 nesting levels — deeper payloads throw).
Accessible HTMLviewHtml() emits the recommended nav[aria-label] > ol shape with aria-current="page" on the live crumb — screen-reader-ready without host markup work.
Breadcrumb rendererTheme-aware plain-text rendering with width-capped left-elision, custom separators/ellipses, per-item renderer closures, and stack-indexed mouse zones that survive truncation.

API

ClassMethodDescription
NavStacknew()Create navigation stack
NavStackpush(string $title, mixed $data = null): selfPush a navigation item (mutates; returns the stack). Refuses titles empty after trimming and sanitizing, and growth past MAX_STACK_DEPTH.
NavStackpop(): ?NavigationItem / popTo(int) / current() / parent() / depth()Pop and inspect the stack
NavStackview(string $separator = ' › '): stringPlain-text crumb trail; titles sanitized for terminal safety
NavStackviewHtml(?callable $href = null, string $label = 'Breadcrumb'): stringAccessible HTML: nav[aria-label="…"] around an ol, last item aria-current="page". $href maps item => URL (links for every crumb but the live one); omit it and the trail renders as plain li text. $label names the landmark for screen readers.
NavStackfilter(string $term): selfNew stack with items whose title or scalar/Stringable payload (array values up to 64 levels) contains $term — ASCII case-fold only; result indices renumber.
NavigationItem__construct(string $title, mixed $data = null) / title()One stack entry; the constructor refuses titles empty after trim+sanitize and over 64 KiB raw
BreadcrumbwithScanner(?Scanner)Attach mouse-click zones per crumb (sugar-mouse Scanner; copied in, never aliased — read it back via scanner()). Zone ids carry the STACK index, so click routing survives truncation.
Breadcrumbscan(string $rendered, ?int $viewportWidth = null, int $row = 1) / hit(col, row) / hitItem(stack, col, row)Feed the rendered string to the owned scanner (optionally clamped to the viewport width, for a row other than 1), then resolve which crumb a terminal cell falls in — hitItem() is the one-call dispatcher returning the clicked NavigationItem
BreadcrumbsetSeparator(string)Set separator between crumbs
BreadcrumbsetMaxWidth(int)Cap trail width; oldest crumbs elide first. 0 (default) disables the cap; negative throws.
BreadcrumbsetTruncator(string $ellipsis)Glyph marking elided crumbs (default …); forged zone-sentinel bytes are stripped, multi-line throws
BreadcrumbsetItemRenderer(\Closure $fn)Per-item custom rendering fn(item, index): ?string — null falls back to the default; returned strings emit RAW. Contract errors throw at render(), not at assignment.
BreadcrumbsetZonePrefix(string)Rename crumb- zone ids (alphabet [A-Za-z0-9._:-]); keeps merged dispatch tables of independent widgets unambiguous
BreadcrumbvisibleIndices(): arrayStack indices that survived the last render's truncation — the map from display position to zone id
BreadcrumbrenderTitles(array $titles): stringRender a pre-trimmed title list (host-owned filtering) instead of a NavStack
Breadcrumbscanner(): ?ScannerRead back the owned (copied-in) sugar-mouse scanner, or null when click zones are off
Breadcrumbrender(NavStack)Render NavStack as breadcrumb string
