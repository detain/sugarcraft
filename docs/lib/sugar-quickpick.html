Fuzzy finder / quick-pick overlay for terminal UIs

Fuzzy-search overlay: a render-and-state component your event loop drives — you decode keys and forward them (type(), cursorUp()/Down()); Enter is answered by the selected() query and hide() is the lifecycle call — neither is input the library consumes, it reads none itself. Composes into any SugarCraft app via the package-local QuickPickHost contract (the old Model name remains as a @deprecated alias). Supports structured Item objects, custom filter predicates, and persistent JSONL history.

Install

composer require sugarcraft/sugar-quickpick

Requirements: PHP 8.3+, no hard extension floor. ext-pcntl and sugarcraft/sugar-pty are both optional and both serve only the opt-in attachSigwinch() resize attach — sugar-pty supplies its automatic SignalForwarder path (and an ext-ffi install floor with it); without either, attachSigwinch() returns false and you drive resizes yourself (invalidateAutoWidth() once per resize, or pass a host installer callable). Everything else is pure string rendering. A UTF-8 capable terminal is expected: the built-in chrome draws ↕ ─ ▏ ⋯ runes, which show as mojibake on legacy non-UTF-8 terminals.

Stability: this package requires its sugarcraft/ siblings at dev-master. A Composer project left on the default stable minimum-stability cannot resolve them — add "minimum-stability": "dev", "prefer-stable": true to the consuming root (or pin the released sugarcraft/* tags once cut). The monorepo publishes all libs together, so sibling versions always line up.

Quickstart — plain strings

use SugarCraft\QuickPick\QuickPick;

$quickpick = QuickPick::new(
    items: ['Ruby', 'PHP', 'Go', 'Rust', 'Python'],
)->withPrompt('Choose language: ');

Quickstart — numbered items + history

use SugarCraft\QuickPick\QuickPick;
use SugarCraft\QuickPick\FilteredItem;
use SugarCraft\QuickPick\History\FileHistory;

$items = [
    new FilteredItem(1, 'apple'),
    new FilteredItem(2, 'banana'),
    new FilteredItem(3, 'cherry'),
];

$quickpick = QuickPick::new($items)
    ->withFilterFn(fn($item) => $item->number() > 0)
    ->withPrompt('> ');

// Persist selections (path you own; files created are 0600)
$historyPath = getenv('HOME') . '/.myapp/history.jsonl';
@mkdir(\dirname($historyPath), 0700, true); // FileHistory creates the file, never its parent
$history = new FileHistory($historyPath);
if ($choice = $quickpick->selected()) {
    $history->append($choice);
}
$allItems = $history->all(); // renumbered 1..N by current load position — archived write-time ordinals are display-ignored

Concepts

QuickPick is a render-and-state component. It owns the filter text, the item list, the cursor and the window offset. Your event loop owns the keys: it decodes them and forwards calls such as type(), cursorDown() and backspace(), then renders view() over the background string the host already has.

Items are plain strings or Item objects. Strings are coerced by ItemFactory, and each coerced string takes its input position as its ordinal. FilteredItem is the numbered Item implementation. The default filter is a case-folded substring match. withRanker() swaps in subsequence scoring, and withFilterFn() adds a predicate that decides which items are candidates at all.

Accepting is two calls, and their order matters. Read selected() first, which returns the highlighted item or null when nothing matches. Then call hide(). hide() is the lifecycle call, not an accept, so reading the selection after hiding is too late.

Tasks

  • Pick one value from a fixed list. Build QuickPick::new(['Ruby', 'PHP', 'Go'])->withPrompt('Choose language: '), forward keys to type(), cursorUp() and cursorDown(), and on Enter read selected() before calling hide().
  • Remember recent choices. After an accept, call FileHistory::append() with the choice. On the next run, all() returns the saved entries, renumbered by their current load position. appendDistinct() is last-wins: older copies of the same value are dropped, the newest occurrence moves to the end, and the file is rewritten whole. The optional entry cap bounds growth.
  • Restrict the candidates. Pass a predicate such as fn(Item $item): bool => ... to withFilterFn(). Only items the predicate accepts reach the text match.
  • Place the overlay over a background. Render the host's own view string, then position the picker with withOffset($x, $y), cap it with withWindowHeight(), and add a border with withBorder(). Positioning is manual, so centering stays with the host.
  • Follow terminal resizes. Call withOnResize() to receive resize events. Call attachSigwinch() to forward SIGWINCH automatically when ext-pcntl or sugar-pty is available. Otherwise call invalidateAutoWidth() once per resize, or supply your own size source with withTtySizeProvider().

Theme, style and color policy

Colorless by default. The frame emits no SGR at all; emphasis reaches the cursor row through text channels a screen reader can speak — the ● bullet and ordinal (both your withItemFormatter's bytes, substitutable to plain ASCII; withNumbered(false) drops the ordinals and keeps the dot) and plain-language chrome rows rendered from the Lang catalog (“↕ showing 1-10 of 40”, “no matches”, “no items”, “N hidden by anchor bias”). Every printed ordinal is a POSITION: coerced strings take their input position across the whole list, replayed history renumbers 1..N at load, and cursor() is the accessor for the selected row's position in what is on screen. SGR appears only where the host opts in (withMatchStyle(), withStyle(), the formatter); honoring NO_COLOR/CLICOLOR is host-side — skip the opt-ins on dumb terminals (the default already needs no color).

Examples

The examples are package-internal demo drivers. They run from a clone with composer install in the lib root, and they drive the VHS tapes.

  • examples/basic.php: a fuzzy finder over ten fruit names, drawn over a background view. Run it with php examples/basic.php.
  • examples/interaction.php: scripted keystrokes against a list of command names. It prints the overlay after the initial state, after type('p') and after type('ph'), and it shows the anchor-bias count when some candidates are hidden. Run it with php examples/interaction.php.

Testing

Run the lib's suite from its root:

composer install && vendor/bin/phpunit

The suite covers the filter and ranker, the geometry and anchor-bias rules, UTF-8 filtering, the SIGWINCH attach, the history store and the help and status bars. ReadmeExampleTest keeps the README's examples executable.

Troubleshooting and FAQ

  • The chrome shows question marks or mojibake. The built-in chrome draws ↕ ─ ▏ ⋯. A legacy non-UTF-8 terminal cannot show them, so run the picker in a UTF-8 terminal.
  • attachSigwinch() returns false. Automatic resize needs ext-pcntl or sugar-pty. Without either, call invalidateAutoWidth() once per resize, or pass a size source with withTtySizeProvider().
  • Composer refuses to resolve the sugarcraft/* siblings. The siblings require dev-master. Add "minimum-stability": "dev" and "prefer-stable": true to the consuming root, or pin released tags once they are cut.
  • Enter returns nothing. selected() returns null when the filter matches nothing or the cursor is out of bounds. Check for null before using the value.
  • The history file is never created. FileHistory creates the file but never its parent directory. Create the directory first, and expect files to be written with mode 0600.
  • Ordinals look wrong after a reload. Ordinals are positions in the list on screen. Replayed history renumbers 1..N at load, and the archived write-time ordinals are ignored for display.

Upstream mapping

The lib is inspired by the quick-pick overlay in Genekkion/theHermit (Go). It is a native PHP port, and three upstream behaviors were deliberately not carried over.

Upstream (Go)SugarCraftDivergence
Framed title row above the listThe header is the prompt and filter lineNo title channel. withPrompt() covers the in-frame label, and hosts render titles in the background view or a StatusBar.
Auto-centering on each resizewithOffset(x, y)Positioning stays manual, because the frame is composed over the host's own string and automatic padding would fight non-full-screen layouts.
Bordered, colored lipgloss styling by defaultFrameless, colorless by defaultwithBorder(), withStyle() and withMatchStyle() are opt-in.

Architecture

The package is one main class and a few helpers. QuickPick is the fuzzy finder overlay. QuickPickHost is the update() and view() composition contract, which carries its state in the return tuple. Item and FilteredItem model the candidates. HelpBar and StatusBar render the lines below the overlay, and both use the Visible concern. ItemFactory coerces string and Item lists. Lang is the chrome text catalog, loaded from lang/en.php. History\FileHistory is the JSONL-backed store. Support\AnsiWalk walks escape sequences by codepoint when highlighting, and Support\UntrustedText guards rendered strings at the trust boundary.
