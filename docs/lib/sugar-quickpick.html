SugarQuickpick

Fuzzy finder / quick-pick overlay for terminal UIs

inspired by Genekkion/theHermit tuifuzzyfinderoverlayquick-pick

Fuzzy-search overlay: a render-and-state component your event loop drives — you decode keys and forward them (type(), cursorUp()/Down()); Enter is answered by the selected() query and hide() is the lifecycle call — neither is input the library consumes, it reads none itself. Composes into any SugarCraft app via the package-local QuickPickHost contract (the old Model name remains as a @deprecated alias). Supports structured Item objects, custom filter predicates, and persistent JSONL history.

Install

composer require sugarcraft/sugar-quickpick

Requirements: PHP 8.3+, no hard extension floor. ext-pcntl and sugarcraft/sugar-pty are both optional and both serve only the opt-in attachSigwinch() resize attach — sugar-pty supplies its automatic SignalForwarder path (and an ext-ffi install floor with it); without either, attachSigwinch() returns false and you drive resizes yourself (invalidateAutoWidth() once per resize, or pass a host installer callable). Everything else is pure string rendering. A UTF-8 capable terminal is expected: the built-in chrome draws ↕ ─ ▏ ⋯ runes, which show as mojibake on legacy non-UTF-8 terminals.

Stability: this package requires its sugarcraft/ siblings at dev-master. A Composer project left on the default stable minimum-stability cannot resolve them — add "minimum-stability": "dev", "prefer-stable": true to the consuming root (or pin the released sugarcraft/* tags once cut). The monorepo publishes all libs together, so sibling versions always line up.

Quickstart — plain strings

use SugarCraft\QuickPick\QuickPick;

$quickpick = QuickPick::new(
    items: ['Ruby', 'PHP', 'Go', 'Rust', 'Python'],
)->withPrompt('Choose language: ');

Quickstart — numbered items + history

use SugarCraft\QuickPick\QuickPick;
use SugarCraft\QuickPick\FilteredItem;
use SugarCraft\QuickPick\History\FileHistory;

$items = [
    new FilteredItem(1, 'apple'),
    new FilteredItem(2, 'banana'),
    new FilteredItem(3, 'cherry'),
];

$quickpick = QuickPick::new($items)
    ->withFilterFn(fn($item) => $item->number() > 0)
    ->withPrompt('> ');

// Persist selections (path you own; files created are 0600)
$historyPath = getenv('HOME') . '/.myapp/history.jsonl';
@mkdir(\dirname($historyPath), 0700, true); // FileHistory creates the file, never its parent
$history = new FileHistory($historyPath);
if ($choice = $quickpick->selected()) {
    $history->append($choice);
}
$allItems = $history->all(); // renumbered 1..N by current load position — archived write-time ordinals are display-ignored

What's in the box

Fuzzy matchingCase-folded substring filter; a candidate must match in the first half of the text (codepoint-based). withRanker() swaps in true subsequence scoring; a rejected-by-bias count surfaces as “N hidden by anchor bias”.
Composition wrapperQuickPickHost contract: update() answers [host, picker] — the updated QuickPick rides the tuple, the host needs no mutable state.
ConfigurableCustom formatter, prompt, match highlight style; window height is a maximum, clamped to the terminal row budget on short screens.
Item interfaceStructured Item objects with number() + value() instead of raw strings.
Custom filter predicateswithFilterFn() applies arbitrary Closure(Item): bool logic — seedable straight through new().
Persistent historyFileHistory stores items as JSONL (version-stamped rows), post-open fd-trust verified, oversized lines dropped at a 64 KiB read cap, with appendDistinct() dedupe and an optional entry cap.
Border & StylewithBorder() frames every row (T-junction separator); withStyle() paints each rendered row via sugar-style.
HelpBar / StatusBarKeyboard-shortcut summary and status message rendered below the overlay.
SIGWINCH resizewithOnResize() + attachSigwinch() forward terminal resize events via SignalForwarder.

Keyboard contract (condensed)

QuickPick reads no input itself — your event loop decodes keys and forwards calls:

KeyCall
printable texttype($s)
Backspacebackspace()
Ctrl+Uclear()
Up / DowncursorUp() / cursorDown() — optional step argument; there are no page keys, call with a step
Home / EndcursorTop() / cursorBottom()
Enter (accept)selected(), then hide() — hide() is not accept(): read the selection before hiding; null means nothing to accept
Esc (cancel)hide()

Accessibility & color policy

Colorless by default. The frame emits no SGR at all; emphasis reaches the cursor row through text channels a screen reader can speak — the ● bullet and ordinal (both your withItemFormatter's bytes, substitutable to plain ASCII; withNumbered(false) drops the ordinals and keeps the dot) and plain-language chrome rows rendered from the Lang catalogue (“↕ showing 1-10 of 40”, “no matches”, “no items”, “N hidden by anchor bias”). Every printed ordinal is a POSITION: coerced strings take their input position across the whole list, replayed history renumbers 1..N at load, and cursor() is the accessor for the selected row's position in what is on screen. SGR appears only where the host opts in (withMatchStyle(), withStyle(), the formatter); honoring NO_COLOR/CLICOLOR is host-side — skip the opt-ins on dumb terminals (the default already needs no color).
