📂 CandyFiles

Dual-pane terminal file manager

inspired by yorukot/superfile file-manager midnight-commander dual-pane

Two panes side-by-side, Midnight Commander style. Tab to swap focus, multi-select, sort cycling, hidden-file toggle, delete-with-confirm. Pure-state transition layer — filesystem is injected, every transition is unit-testable.

Install

composer require sugarcraft/candy-files

Quickstart

# 1. Composer consumer — the package bin (composer.json "bin"):
vendor/bin/candy-files [LEFT_DIR] [RIGHT_DIR]

# 2. Source checkout of this repo:
composer install
./bin/candy-files [LEFT_DIR] [RIGHT_DIR]

# 3. Rolling phar — published on GitHub Releases under the
#    candy-files/dev tag (with .sha256 and .sig sidecars):
php candy-files.phar [LEFT_DIR] [RIGHT_DIR]

# Flags (answered before the positional directory scan):
#   --version  build stamp — phar-aware via Support\Version
#   --help/-h  usage
# A missing/unreadable start directory fail-fasts with exit 1
# ("left/right directory does not exist: ").
# Default: left = cwd, right = $HOME.
# Size honesty: the panes split the live terminal width from ~82 columns
# up (40-cell minimum each, wrapping below — no horizontal scroll), and
# there is no scroll viewport: listings longer than the frame are clipped
# (Home/End/search reach the rest).

# Keys
# Tab        Swap focus
# ↑ / k      Move up
# ↓ / j      Move down
# Home / g   Top
# End / G    Bottom
# Enter / →  Open directory
# ← / h      Up one directory
# Space      Toggle selection + advance
# s          Cycle sort order (6 modes)
# .          Toggle hidden files
# c          Copy selection or cursor → inactive pane (y confirm)
# m          Move selection or cursor → inactive pane (y confirm)
# R          Rename cursor entry — type new name, Enter commits, Esc cancels
# d          Delete (selection or cursor) — y to confirm
# r          Refresh active pane
# q          Quit
# /          Search mode — fuzzy filter of the active directory; k/j move, Enter opens dirs, Esc exits
# Escape     Exit search mode · clear selection (outside prompts)
# t          Duplicate current tab
# Ctrl+w     Close current tab
# Ctrl+Tab   Cycle to next tab — terminals that report modified Tab
# Ctrl+Shift+Tab  Previous tab
# Ctrl+PgUp  Next tab · Ctrl+PgDn  Previous tab — tmux/browser terminals may intercept modified Page keys
# u / Ctrl+z Undo last operation
# Ctrl+y     Redo last undo

What's in the box

Dual panesLeft + right; Tab swaps focus. Each pane has its own cwd, cursor, selection, sort, hidden-flag.
Multi-selectSpace toggles + advances. Selection survives r relist and sort; it is cleared on navigation (name-keyed selection across directories would let a d+y destroy same-named entries elsewhere). Escape clears.
Six sort modesname / mtime / size, asc / desc — s cycles.
Hidden-file toggle. hides / shows dotfiles.
Copy / Move / Renamec/m stage to the inactive pane, y commits. R opens a text-entry rename submode — type the new name, Enter commits, Esc cancels. Undo covers delete, move and rename (copy undo is informational).
Delete-with-confirmd stages, y commits — protects against fat-finger deletes.
Injectable FSFsLister closure — swap for a fixture lister in unit tests with no tmp dirs.
RequirementsPHP ^8.3 with ext-intl and ext-mbstring — both hard-required transitively by sugar-core, whose cell-width math segments through ICU, so composer install is the step that refuses on a bare php-cli machine.
Live search/ fuzzy-filters the active pane's current directory (not recursive). ↑↓/k/j move the result cursor — so k/j cannot be typed into a query; / cannot be typed either. Enter opens a directory result; on a file result it just exits search. Backspace-to-empty exits.
Tab managementt duplicates the current tab, Ctrl+Tab/Ctrl+Shift+Tab cycle (needs a terminal that reports modified Tab; Ctrl+PgUp/Ctrl+PgDn are the alternative — tmux and browser terminals may intercept modified Page keys), Ctrl+w closes (refuses the last tab).
Undou or Ctrl+z restores the last delete / move / rename; Ctrl+y redoes.
Localized promptsThe executable activates a language detected from $LC_ALL/$LANG (16 catalogues, English default). Confirmation gates honor the affirmative each locale's prompt teaches — a German (j/n) answers j, a Russian (д/н) answers д — and y works everywhere.

Navigate

Tab-swap, multi-select, sort cycle, delete-with-confirm.

Search

Type "/" to fuzzy-filter the active directory, k/j (or arrows) move results, Enter opens directories.

Multi-select

Space toggles selection, d+y deletes all selected.

Tab management

t duplicates, Ctrl+Tab (or Ctrl+PgUp/PgDn) cycles, Ctrl+w closes.

Sort cycle

s cycles through all 6 sort modes: name/mtime/size × asc/desc.

Undo delete

u or Ctrl+z restores the last deleted entry.

Hidden-file toggle

. reveals and hides dotfiles.
