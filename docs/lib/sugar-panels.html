SugarPanels

H/V panels with flex/natural sizing, borders, nesting, and stateful delta rendering

inspired by treilik/bubbleboxer layoutboxborderuipaneltui

Compose terminal layouts with horizontal and vertical panels. Attach borders, hint minimum and maximum sizes, let flex children fill the rest, and nest arbitrarily deep.

Install

composer require sugarcraft/sugar-panels

Quickstart

use SugarCraft\Panels\SugarPanels;

$panels = SugarPanels::new();

$layout = $panels->vertical(
    $panels->horizontal(
        $panels->leaf("Left panel"),
        $panels->leaf("Right panel"),
    )->withBorder(false)->withGrow(),
    $panels->leaf("Bottom bar")->withBorder(false),
)->withBorder(false);

echo $panels->render($layout, 60, 7);

Every node is bordered by default — a plain nested layout paints a doubled frame at each level. Containers are usually scaffolding, so turn their frames off with withBorder(false) (or wrap a subtree in noBorder(), which suppresses every frame and every divider below it), and give the viewport enough rows to hold what you asked for. That prints (protocol and styling stripped):

╭────────────────────────────╮╭────────────────────────────╮
│Left panel                  ││Right panel                 │
│                            ││                            │
│                            ││                            │
│                            ││                            │
╰────────────────────────────╯╰────────────────────────────╯
Bottom bar

The horizontal row carries withGrow(), so it flexes to six of the seven rows while Bottom bar — the fixed child — claims its measured natural single row at the bottom. Every row the renderer emits is padded to the viewport width, Bottom bar's included.

What's in the box

H/V panelsRow and column composition with weighted sizing.
BordersPreset or custom border styles per panel.
Nested layoutsArbitrarily deep nesting — grids within grids.
Word-wrapText reflows inside the region at render time.
ANSI-awareStyled content places by visible columns; a clipped or unbalanced span is auto-reset so colour stays inside its box.
Diff renderingSelf-positioning delta frames repaint only the cells that changed — light SSH payloads, no full-screen flicker.
Trust boundaryHostile text is repaired, not rejected: UTF-8 mended, zone sentinels stripped, stray controls normalised at the paint choke.
Flex / growwithFlex/withGrow children fill leftover space — fixed header/status, filling content.

Styled content stays trusted input — escape sequences ride through by design; see the README's Trust boundary section.
