Terminal UIs that taste like candy.

SugarCraft is a PHP-native TUI ecosystem — forty libraries and twenty-two apps (sixty-two packages total). MVC-style Model–Update–View runtime, declarative styling, animation, charts, forms, SSH-served apps, telemetry, file managers, an AI chat shell. Composer-installable, PHP 8.3+, async on ReactPHP.

Built for the things Symfony Console can't do.

Persistent render loops, mouse + keyboard, alt-screen, async work without blocking the UI, multi-tenant SSH-served TUIs, charts and sparklines, animated spinners, multi-page forms, Markdown rendered straight to ANSI. The boring parts of CLI tooling — argv parsing, exit codes — pair perfectly with whatever Console framework you already use.

Five layers, no surprises.

SugarCraft is a layered architecture with one responsibility per layer. Dependencies flow one way through the stack, so you can grab as much or as little as you need.

1. Foundation
SugarCraft::Util — Ansi, Color, ColorProfile, Width, Tty. Depended on by everything below.
2. Render + physics
SugarStyle — styling, SugarSpring — spring physics. Pure rendering / pure math — no I/O.
3. Runtime
SugarCraft — Model / Msg / Cmd / Program. An MVC-style Model–Update–View loop on ReactPHP with command and subscription hooks.
4. Components
SugarWidgets (components), SugarCharts (charts), SugarForms (forms), SugarMouse (mouse zones). Composable widgets that drop into your Model.
5. Tooling libs + apps
Tooling libs: SugarMarkdown (markdown → ANSI), SugarCli (CLI chrome), SugarSshServer (SSH), SugarMetrics (telemetry), SugarLog (logging), SugarColorprofile (color detection).
CLI apps: CandyScriptui (one-shot CLI helpers), CandyMdview (markdown), CandyAnsiInspect (ANSI inspector), CandyCodeshot (code → SVG), CandySshLauncher (SSH launcher), CandyGitServer (git server), CandyKv (key/value store), CandyMail (email sender).
TUI apps: CandyStarter, CandyTetris, CandyFiles, CandyCode, CandyGit, CandySql, CandyCodetime, CandyMinesweeper, SugarAnimation, CandyTop, CandyFlappy.
Web UI: CandyCodeWeb (browser face of CandyCode).
⚡

Async-first

ReactPHP event loop under the hood. Cmds are closures dispatched on the loop; the render thread never blocks on I/O.

📐

Immutable values

Immutable value objects across the fleet — with*() returns a new instance. sugar-style carries a documented naming exception (bare bold()/fg() builders over a private with()).

🧪

Testable by design

Pure update functions and snapshot ANSI tests. No tmp dirs, no mocks for the renderer — just assert against the frame.

🎨

One styling vocabulary

Every package speaks SugarCraft\Style\Style. Mix SugarMarkdown output into a SugarWidgets Viewport, wrap that with a SugarStyle Border — they all compose.

🔐

SSH the easy way

SugarSshServer leans on ForceCommand. sshd handles auth, ciphers, fail2ban, audit logs — you get a clean middleware programming model.

📦

No native extensions

Pure-PHP base flow. ext-pcntl, ext-gd, ext-ssh2 are optional for niche features.

From composer require to a working counter in ten lines.

Install the umbrella, drop the snippet below into a file, php counter.php. ↑ ↓ to count, q to quit.

1. Install

composer require sugarcraft/sugarcraft

2. Write the model

use SugarCraft\Core\{Cmd, KeyType, Model, Msg, Program};
use SugarCraft\Core\Msg\KeyMsg;

final class Counter implements Model {
    public function __construct(public readonly int $n = 0) {}
    public function init(): ?\Closure { return null; }

    public function update(Msg $msg): array {
        if ($msg instanceof KeyMsg && $msg->rune === 'q') return [$this, Cmd::quit()];
        return [match (true) {
            $msg instanceof KeyMsg && $msg->type === KeyType::Up   => new self($this->n + 1),
            $msg instanceof KeyMsg && $msg->type === KeyType::Down => new self($this->n - 1),
            default => $this,
        }, null];
    }

    public function view(): string { return "n = {$this->n}\n↑ ↓ to count, q to quit\n"; }
}

(new Program(new Counter()))->run();

3. Run it

php counter.php

Want a project skeleton instead?

composer create-project sugarcraft/candy-starter my-app scaffolds a runnable counter app with PHPUnit wired up — see CandyStarter.
