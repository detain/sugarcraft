Style, Border, Table\Table, Listing\ItemList, Tree\Tree, Layout::joinHorizontal/joinVertical, Layout::place, multi-layer Canvas, and Theme — the canonical color palette for all SugarCraft libs. The rendering core is pure — no I/O (an optional Output facade wraps print/printf/fprint) — so you can render frames inside a unit test.

Install

composer require sugarcraft/sugar-style

Quickstart

use SugarCraft\Style\{Style, Border, Layout, Position};
use SugarCraft\Style\Table\Table;
use SugarCraft\Core\Util\Color;

$banner = Style::new()
    ->bold()
    ->foreground(Color::hex('#ff5f87'))
    ->padding(0, 2)
    ->render('hello, styled world');

$table = Table::new()
    ->headers('Name', 'Age')
    ->row('Alice', '30')
    ->row('Bob', '25')
    ->border(Border::rounded())
    ->render();

echo Layout::joinVertical(Position::LEFT, $banner, $table);

What's in the box

StyleForeground / background, bold / italic / underline, overline, padding, margin, width, alignment. Immutable value object; setters keep lipgloss's bare names (fg(), bold(), width()) and each returns a new Style.
BorderEight built-in styles + custom. Border::rounded(), thick(), double(), block(), hidden(), normal(), ascii(), markdownBorder().
TableHeaders, rows, per-cell styleFunc. ANSI-aware width calc with grapheme cluster support. Optional wrap() callback: every line it returns renders, so a wrapped row spans several physical lines.
List + TreeBulleted lists and ASCII trees with custom enumerators.
LayoutjoinHorizontal, joinVertical, place, plus the ratatui-style constraint solver (Layout\Layout::vertical([...])->split()) and RegionBridge for handing rectangles between sugar-constraints and sugar-cellbuffer.
CanvasMulti-layer compositor. Z-ordered overlays merged by a cell-aware row splice (no alpha blending — upper cells replace lower ones), ideal for modals + tooltips.
ThemeSingle source of truth (SSOT) color palette. 10 named factories (dark/light/dracula/tokyoNight/oneDark/githubDark/solarized*/ansi/adaptive). 13 color slots (foreground/background/primary/secondary/accent/muted/error/warning/success/info/border/separator/cursor). All with*() setters return a new Theme. adaptive() reads $COLORFGBG: any numeric slot (0-255) in the last field decides light vs dark by luminance (e.g. 7/15 light, 0/8 dark); unset, non-numeric or out-of-range falls back to dark.
Embedded titles + seamsbtop-style box titles: Border::withEmbeddedTitle() brackets text in junctions (╭─┐cpu┌────┐12:00┌───────╮) on any of six anchors; Border::seam() picks the ┬ ┴ ├ ┤ ┼ rune where an internal divider meets the frame, preserving the border family.
Color degradationA Style carries a ColorProfile and render() downsamples to it, as charmbracelet/colorprofile's Writer does: TrueColor → 38;2, Ansi256 → 38;5, Ansi → 30..37/90..97, Ascii (what NO_COLOR selects) drops color but keeps bold/italic/underline and OSC 8 links, and NoTty strips every escape — including ones carried in by pre-styled content, a transform() or a border title — while padding, borders and alignment stay. Tier rewrites apply to RGB colors; palette-slot colors (Color::ansi(n)) always emit their 30..37/90..97 form at every tier.
Underline truthSub-style shapes ride the numeric SGR 4:N form emitted only alongside underline() — terminals that ignore 4:N typically draw no underline at all (no plain SGR 4 companion is sent). SGR 58 has no 4-bit spelling, so at the Ansi tier the underline color is applied through the foreground attribute instead — it recolours the glyphs rather than tinting the rule.

Embedded border titles

use SugarCraft\Style\Border;
use SugarCraft\Style\Border\TitleAnchor;
use SugarCraft\Style\Style;

$border = Border::rounded()
    ->withEmbeddedTitle('cpu')
    ->withEmbeddedTitle('12:00', TitleAnchor::TopCenter)
    ->withEmbeddedTitle('mem', TitleAnchor::BottomLeft)
    ->withEmbeddedTitle('disk', TitleAnchor::BottomLeft);

echo Style::new()->border($border)->width(24)->render('load 0.42');
// ╭─┐cpu┌────┐12:00┌───────╮
// │load 0.42               │
// ╰─┘mem└─┘disk└───────────╯

echo Border::normal()->seam(left: true, right: true, up: false, down: true); // ┬

Troubleshooting

Colors still print under NO_COLOR, or into a pipe

Style::new() renders TrueColor unless a process-wide default has been pinned, and sugar-style never reads the environment itself. Negotiate the terminal's tier once at startup and pin it with Style::setDefaultProfile(). Every Style created afterwards downsamples to that tier, and NoTty strips every escape. The detection reads NO_COLOR, CLICOLOR, CLICOLOR_FORCE and TERM=dumb through sugar-colorprofile.

use SugarCraft\Core\Util\ColorProfile;
use SugarCraft\Style\Style;

Style::setDefaultProfile(ColorProfile::detect(null, STDOUT));

Theme::adaptive() picks the dark palette on a light terminal

adaptive() reads only the last field of COLORFGBG. A value in the form fg;bg with a background index from 0 to 255 decides light or dark by that colour's luminance. When the variable is unset, has no ;, or holds a non-numeric or out-of-range background, the result is the fallback, which is dark by default. Many terminals never set COLORFGBG, so on those the fallback decides every time. Pass adaptive(false) to make the fallback light, or choose Theme::light() or Theme::dark() when the host knows its background.

A wrapped table cell stays on one line

A Table::wrap() callback must return a list of physical lines, not a single string with embedded newlines. Each element of the returned array becomes one rendered line of the row. Split the wrapped text into an array before returning it, so the row grows to match.

use SugarCraft\Core\Util\Width;
use SugarCraft\Style\Table\Table;

$table = Table::new()
    ->headers('Note')
    ->row('A long note that should wrap across several lines')
    ->wrap(fn (string $cell, int $colWidth): array =>
        explode("\n", Width::wrapAnsi($cell, $colWidth)))
    ->render();

An overlay hides the layer beneath it instead of blending

Canvas composites layers in z-order, and an upper cell replaces the lower cell it covers. There is no alpha blending, so every cell inside an overlay's footprint shows the overlay's content. Cells outside that footprint still show the base layer. Size the overlay to the area it needs, and keep the base visible around it.

withEmbeddedTitle() adds nothing to the border

An empty string is treated as no title, so the edge stays identical to an untitled border. The layout also budgets exactly one cell per junction. A title that is too long for its edge shrinks to fit and ends in …, so it is cut rather than wrapped. Widen the Style with width() or shorten the title when the cut text matters.

Changelog and versioning

The package has no separate changelog file and no release tag yet, so it publishes only dev-master. Its history is the commit log of the sugar-style/ directory in the monorepo, at github.com/detain/sugarcraft/commits/master/sugar-style. Two deprecated accessors on Style, getDefaultProfile() among them, have a docblock that reads REMOVED-IN: 2.0.0, so they go in 2.0.0. The deprecated Border::getTitles() alias carries no removal version yet, so do not plan its removal for 2.0.0.
