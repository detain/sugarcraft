Terminal Git client on the SugarCraft stack — a TUI for staging, branching, log, diff, stash, worktrees and rebase. Status, branches and log panes cycle with tab; P opens the diff viewer with per-hunk staging, and u / Ctrl+r undo and redo the last mutations through a 100-entry history. Every verb shells out to the user's own git — no reimplementation — so your existing hooks, GPG signing and credentials ride along; the plumbing verbs never consult git aliases, though, so they run git's built-ins exactly as typed.

Install

composer require sugarcraft/candy-git

Quickstart

# Run from any git working tree:
vendor/bin/candy-git
// Or wire your own driver in PHP:
use SugarCraft\Core\Program;
use SugarCraft\Core\ProgramOptions;
use SugarCraft\Git\App;
use SugarCraft\Git\Git;

$git = new Git(getcwd());
(new Program(App::start($git), new ProgramOptions(useAltScreen: true)))->run();

Trust boundary

Opening a repository executes its configuration unless told otherwise, and git has several config keys that name executables. CandyGit runs every git call through a fixed argument prelude — -c core.quotepath=off -c core.fsmonitor=false plus --no-ext-diff on diffs — that disarms the repo-controlled execution channels it can neutralize without breaking legitimate tooling; merge drivers are enumerated on the merged config scope and each overridden with false (resolved to the inert coreutils binary) before any merge-capable command, and a driver shape that cannot be re-expressed refuses the merge outright. Filter drivers (clean / smudge / process) are detected and announced on stderr rather than silently disarmed — git-lfs-class tooling depends on them working — with CANDY_GIT_STRICT_FILTERS=1 turning the posture into a refusal. Children spawn through a single proc_open site with a pinned environment. A hostile clone can still reach a trusted global git-lfs driver through its .gitattributes: operate only repositories you trust. The full disclosure lives in the README's Trust boundary section.

Internationalization

User-facing strings use SugarCraft\Git\Lang::t(). All keys are in lang/en.php under the git namespace — Lang::t() bakes the namespace into lookups, so Lang::t('timeout') resolves the registry key git.timeout; always call through SugarCraft\Git\Lang rather than the raw registry.

The table above is an excerpt; lang/en.php is the full roster of 137 keys. To localize, copy lang/en.php to lang/<code>.php and translate the values.

The cli.not_a_repo refusal fires when git rev-parse --absolute-git-dir fails for the working directory — linked worktrees, where .git is a file rather than a directory, are accepted.
