Built on league/commonmark + SugarStyle. Word-wrap, OSC 8 hyperlinks, syntax highlighting, nine built-in themes plus custom JSON themes.

Install

composer require sugarcraft/sugar-markdown

Quickstart

use SugarCraft\Markdown\{Renderer, Theme};

// render() emits no trailing newline on purpose — those bytes are
// exactly what stream() yields for a one-chunk document — so the
// echo supplies its own "\n" as a second operand.
echo (new Renderer())->render(<<<MD
# Welcome

A few **bold** and _italic_ words, with `inline code` and a
[link](https://example.com).

- one
- two
- three

```php
echo "hello world";
```
MD), "\n";

// Custom theme from inline JSON; for the file variant
// (Theme::fromJson($path)) see examples/custom-theme.php.
$theme = Theme::fromJsonString('{"heading1":{"bold":true}}');
echo (new Renderer($theme))->render("# Styled\n");

What's in the box

CommonMark parserHeadings, paragraphs, lists, blockquotes, code blocks, tables, rules, links, images. Raw HTML (inline + block) passes through as inert literal text with theme styling, control-stripped regardless of the sanitize flag; refused URL schemes never open an OSC-8 target — see the README Link safety policy.
Nine presets (notty aliases plain)ansi, plain, notty, ascii, dark, light, dracula, tokyo-night, pink.
Custom JSONTheme::fromJsonString('{"heading1":{"bold":true}}') takes the JSON directly and throws InvalidArgumentException on malformed JSON or a non-object payload; Theme::fromJson($path) reads the same shape from a file and throws RuntimeException carrying the read error, rather than leaking a PHP warning.
Word-wrapConfigurable column width; honours SGR + grapheme cluster widths. List items and blockquotes charge only their own indent or 2-cell bar, so nested lines fit the wrap width as in glamour.
OSC 8 hyperlinksDisable at the library with withHyperlinks(false) (short alias hyperlinks(false)) for terminals that don't support them; the --no-hyperlinks spelling belongs to the candy-mdview CLI. Email autolinks render the address hyperlinked to mailto: with no href suffix.
Streamingstream(iterable $chunks) yields rendered sections as markdown arrives; for every split tested, chunk boundaries never change the assembled output — the stream equals render() byte for byte. Link reference definitions carry across sections; a section with an unresolved [..] is held back until a later definition resolves it or the document ends.
Syntax highlightingCode blocks tokenised + coloured per language.

Every user-facing string goes through Lang::t() (src/Lang.php) with 16 locales shipped in lang/ — consumers such as candy-mdview surface localized messages like theme.read_failed.
