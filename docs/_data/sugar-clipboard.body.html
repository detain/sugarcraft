Clipboard access for SugarCraft terminal programs. The planned backend is OSC 52, the terminal escape sequence that asks the emulator to set its clipboard, so a copy also works over SSH and inside multiplexers when the terminal allows it. The OSC 52 writer in candy-git-server has no consumers today and moves here as this backend. It is a skeleton: its namespace and packaging exist, and the API arrives in a later change.

Install

composer require sugarcraft/sugar-clipboard

Requires PHP 8.3 or newer. The package has no runtime dependencies beyond PHP.

API reference

This library declares no public classes, interfaces, traits or enums yet, so there is no API listing. The reference is generated from the source once the first public type lands.
