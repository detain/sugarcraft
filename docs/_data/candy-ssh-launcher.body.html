Launch candy-ssh-launcher, pick a host, hit Enter — the current process is replaced with ssh connecting to it. Reads YAML or JSON; supports identity files, ssh options, ProxyJump.

Install

composer require sugarcraft/candy-ssh-launcher

Quickstart

# ~/.config/wishlist.yml
- name: production
  host: prod.example.com
  port: 2222
  user: deploy
  identity_file: ~/.ssh/prod-deploy

- name: staging
  host: stage.example.com
  user: deploy

- name: jumpbox
  host: bastion.example.com
  options:
    - ServerAliveInterval=30
    - ProxyJump=gw.example.com

What's in the box

Config discovery--config ▸ ./wishlist.{yml,yaml,json} ▸ ~/.config/wishlist.{yml,yaml,json} — first file that exists wins at each tier.
YAML schemaname, host, port, user, description, identityFiles[] (or the singular identity_file / identityFile aliases), proxyJump, options[].
Type-filterType to fuzzy-narrow the list (sugar-fuzzy Smith–Waterman scoring, live match count, 16 locales).
ProxyJump / OptionsPass any ssh option through the entry's options array.
pcntl_execReplaces the launcher process — no double-shell — so signals + exit codes propagate cleanly.
Composer-installableSingle binary at vendor/bin/candy-ssh-launcher.

API

ClassMethodDescription
Endpointnew(name, host)Create SSH endpoint (port, user, identityFiles, description, proxyJump, options optional)
EndpointwithName(name) · withHost(host) · withPort(port) · withUser(user)Fluent setters — each returns a new endpoint
EndpointwithIdentityFiles(paths[])Set identity files, in order, each passed to ssh as its own -i
EndpointwithDescription(text) · withProxyJump(host) · withOptions(options[])Fluent setters — each returns a new endpoint
EndpointparsePort(host, raw)Validate a port value (1–65535); junk is refused naming the endpoint
Configload(path)Load endpoints from YAML/JSON (format auto-detected)
Configparse(raw, hintPath)Parse config text directly (extension hint, else JSON iff the payload opens with [ or {)
ConfigimportFromSshConfig(path)Import endpoints from ~/.ssh/config
Pickerpick(endpoints)Interactive selection (null on cancel or empty endpoint list)
Launcher__construct(executor)Optional callable executor seam for embedding and tests
Launcherdispatch(endpoint, binary)pcntl_exec handoff — never returns on success; the default executor throws a RuntimeException naming the binary when exec fails
