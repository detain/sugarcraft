A Model Context Protocol client core the whole ecosystem can share: JSON-RPC 2.0 envelopes, a newline-framed stdio transport with a bounded, orphan-proof child lifecycle, the initialize/tools handshake, and deny-before-allow tool narrowing. Here "client" means the tool-CALLING side: this library spawns and drives an MCP server child process; it does not host one. Extracted from candy-code's src/MCP stack and McpMessage codec, so every surface that talks to an MCP server rides the same framing, the same timeouts, and the same error shapes. First-party — MCP is a spec, not a Go port.

Install

composer require sugarcraft/sugar-mcp-client

Quickstart

use SugarCraft\McpClient\StdioMcpServer;

$server = new StdioMcpServer(
    name: 'everything',
    command: 'npx',
    args: ['-y', '@modelcontextprotocol/server-everything'],
);

$server->start();              // initialize → initialized → tools/list, one 60s clock
foreach ($server->listTools() as $tool) {
    echo $tool->name, ' — ', $tool->description, PHP_EOL;
}

$result = $server->callTool('echo', ['message' => 'hi']);
// normally ['content' => [['type' => 'text', 'text' => '…']]], or ['error' => …]
// naming the CAUSE — a failed call never throws and never answers bare.

$server->stop();               // close pipes first, then TERM→KILL→reap. Never an orphan.
// __destruct calls stop() for you if you forget.

The model

McpMessageJSON-RPC 2.0 envelope: parse() / request() / notification() / success() / error(); a resultSet sentinel keeps explicit "result": null representable; toJson() is the wire and fails closed on unencodable payloads, toArray() is inspection.
McpTool / McpServerOne tool definition value object with a well-typedness gate that refuses malformed server output — including control bytes in names — plus the start/stop/listTools/callTool interface.
StdioMcpServerargv-array proc_open child, newline-delimited (NDJSON) framing, 64 KiB rolling stderr tail absorbed on every wait set, one wall clock across the whole handshake, protocol-version negotiation, and a per-second handshake beat via start(onWait:).
ExchangeLockSerialises whole request/response exchanges when forked processes share one stdio connection; records a W/R phase so the next holder resynchronises after a killed one; the file is created at mode 0600, verified before any payload, and a filesystem that refuses the mode fails the open loudly.
McpRouterDeny-patterns-then-allowlist narrowing over any set of McpServer instances; fnmatch globs; empty allowlist means allow-all; malformed entries fail loud.
Server requests & trustA server's own requests (ping, roots/list, elicitation/create) are answered inline while a call is in flight — default ping acknowledged, anything else refused "Method not found" — with the handler's wall clock paused out of the call's budget. Running a configured stdio entry executes third-party code as the invoking user with the FULL parent environment: see the README's Trust boundary.

Use it for

  • Speaking MCP from any PHP process — spawn a stdio server child, handshake, list and call tools, with the framing and timeout discipline already fought for.
  • Agent tool surfaces — narrow each agent's visible tools with globs and deny-before-allow, the same semantics candy-code uses.
  • Bounded subprocess I/O — the transport doubles as a reference for newline-framed JSON-RPC over pipes with no deadlock, no silent wedge, and no orphaned grandchildren.
