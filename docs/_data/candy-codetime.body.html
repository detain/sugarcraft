Tracks edit-time per project / language to a local append-only JSONL file — or to an optional embedded SQLite backend via --backend=sqlite (no cloud, no database server either way) — and renders a SugarCharts-driven dashboard. Editor plugins record heartbeats with the push CLI subcommand; the dashboard reads whichever backend you picked.

Install

composer require sugarcraft/candy-codetime

Quickstart

# Editor plugin / cron / git hook pushes a heartbeat:
candy-codetime push sugarcraft php src/App.php 60

# Open the dashboard:
candy-codetime

# Override the data dir:
CANDY_CODETIME_DIR=/var/data/codetime candy-codetime

Formerly shipped as sugar-tick: the old SUGARTICK_DIR // @rename-keep env var and the ~/.local/share/sugar-tick data directory are still // @rename-keep honoured once and migrated automatically on first launch.

What's in the box

Heartbeat schema{time, project, language, file, duration} — JSONL, one beat per line.
Per-day filesStorage is one YYYY-MM-DD.jsonl per day — append-only, easy to ship to cold storage.
Top projects + languagesTwo ranking panes side-by-side, sorted by total time descending.
Daily timelineSugarCharts Sparkline driven by per-day minute buckets.
Window navigation← / → shift the 7-day window; r reloads.
Pure foldingStats::compute is total-input deterministic — every dashboard test runs against fixed beats.
