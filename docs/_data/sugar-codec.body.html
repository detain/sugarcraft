The YAML reading and writing that SugarCraft tools need for configuration and data files. Today two copies exist: a hand-written YAML subset in the candy-ssh-launcher config reader, and the YamlDialect engine in candy-kv, which carries two parsing engines. This library is the planned single home for both. It is a skeleton: its namespace and packaging exist, and the parser and emitter arrive in a later change.

Install

composer require sugarcraft/sugar-codec

Requires PHP 8.3 or newer. The package has no runtime dependencies beyond PHP.

API reference

This library declares no public classes, interfaces, traits or enums yet, so there is no API listing. The reference is generated from the source once the first public type lands.

Status

The package currently ships only its PSR-4 wiring under SugarCraft\Codec\. No public API exists yet, so there is no quickstart to show. The tools keep their own YAML code until the codec lands here.
