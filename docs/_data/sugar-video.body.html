Terminal video player — plays mp4, gif, avi, webm, animated webp on the fly, rendering each frame as ASCII, ANSI 256-color, truecolor half-/quarter-blocks, or via modern graphics protocols (sixel / kitty / iTerm2), with WebVTT subtitle overlays.

Install

composer require sugarcraft/sugar-video

Quickstart

php examples/play.php video.mp4           # play a video
php examples/play.php                    # synthetic test pattern (no file needed)
// Programmatic (mode auto-detects terminal capability):
use SugarCraft\Video\Player;
$player = Player::open('clip.mp4', cellsW: 80, cellsH: 24);   // mp4/avi/webm decode through ffmpeg
(new \SugarCraft\Core\Program($player))->run();

What's in the box

Multi-format decodeffmpeg for mp4/avi/webm, pure-PHP + ext-gd for GIF and animated WebP (a RIFF container walk with per-frame GD decode). No external deps beyond the ffmpeg binaries for the video containers.
8 rendering modes + autoascii, ansi256, truecolor, half-block, quarter-block, sixel, kitty, iTerm2 — Player::open() and Reel default to probing the terminal and picking the best available.
Auto terminal resizeSIGWINCH handler re-scales video to fit the new terminal dimensions without restarting playback.
Seek + speed controlKeyboard-driven seek (arrows, 0-9) and speed control ([ / ]) with frame-skip resync; ffmpeg input seeking (-ss before -i) for instant jumps on long streams.
WebVTT subtitlesReel::withSubtitles('clip.vtt') parses WebVTT (lenient enough for most SRT files) and paints the active cue as one caption line under the frame in every mode.
Audio companionAudioPlayer shells out to ffplay or mpv as the audio master clock; pausing terminates and re-spawns the companion so no silent zombie burns CPU, and degrades gracefully when no audio track is present.
Remote sources with headersReel::openUrl() forwards an SSRF guard (host allowlist, credentials in the URL refused) and rides request headers onto ffmpeg for signed CDN URLs; audio re-presents the same headers.
Loop playbackReel::new()->withLoop(true)->play() loops from end back to start automatically.
Delta repaintOnly changed cells are re-rendered each frame, dramatically reducing output for static scenes.
SGR run-length coalescingAsciiRenderer emits color SGR codes only on color transitions (~60% output reduction for typical frames).
