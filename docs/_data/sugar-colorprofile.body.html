Detect the terminal's color capability (TrueColor / Ansi256 / Ansi / Ascii / NoTTY — the five detection-emittable levels) and degrade colors, strings and whole output streams to match it — one-way, TrueColor down, never up; an opt-in perceptual family picks the nearest palette color when a degraded value must land on a fixed set. Detection reads the shared env ladder, honoring NO_COLOR, FORCE_COLOR, TERM=dumb and the reduced-motion request. It ports the concepts of charmbracelet/colorprofile, which detects a terminal's color profile and downgrades output to match.

Install

composer require sugarcraft/sugar-colorprofile

No tagged releases ship yet — Packagist serves the dev-master branch only, so require it as sugarcraft/sugar-colorprofile:dev-master; on a default-stable project a bare sugarcraft/sugar-colorprofile request does not resolve.

Requires PHP 8.3+ and the ext-mbstring extension — the UTF-8 sweep in Env::sanitize and the TERM cap run mb_convert_encoding/mb_strcut unguarded, and until this was declared the dependency was satisfied only transitively via sugar-core while the docs claimed the opposite. The probes' optional posix_* calls remain feature-detected, and an absent or unreadable infocmp child degrades the phase-2 answer instead of failing. Direct dependencies: sugarcraft/sugar-core, react/event-loop, react/child-process, react/promise (the latter three back the async AsyncProbe consult).

Supported targets: POSIX terminals. The phase-2 infocmp consult is POSIX-only by design — it queries the compiled terminfo database. The env ladder's Windows/macOS legs (WT_SESSION, the TERM_PROGRAM=iTerm.app hint, the only macOS terminal name matched, since Apple_Terminal is deliberately excluded) are untested by this repository's CI, whose ladder legs run on Linux only; on Windows the library answers from the env ladder alone. Case matters more there than anywhere else: env keys are matched case-exactly, while the Windows environment block is case-insensitive at the OS layer — an unusual spelling such as No_Color can exist in the shell's view and still miss detection, because the library deliberately does not alias-match env keys (Env::resolve).

Quickstart

use SugarCraft\ColorProfile\{Color, ColorProfile, Palette, ProfileWriter};

$profile = Palette::detect(STDOUT);      // ColorProfile::TrueColor | Ansi256 | Ansi | Ascii | NoTTY
echo $profile->label();                  // e.g. "No TTY" when piped

// Downsample one color to an explicit profile
$coral = Color::parse('#ff6b6b');        // r 255, g 107, b 107
$c256  = Palette::toProfile($coral, ColorProfile::Ansi256);
echo $c256->toAnsi256Index();            // 203
echo $c256->toAnsi256Foreground();       // "\x1b[38;5;203m"

// Rewrite every color in a string for a given profile
$ansi = (new Palette())->withProfile(ColorProfile::Ansi256)
    ->degrade("\x1b[38;2;255;107;107mhi\x1b[0m"); // "\x1b[38;5;203mhi\x1b[0m"

// Or wrap a stream and let it degrade (or strip, under NoTTY) on write
ProfileWriter::wrap(STDOUT)->write("\x1b[38;2;107;80;255mFancy\x1b[0m\n");

Concepts

A color profile is the richest color an output stream can carry: TrueColor, Ansi256, Ansi, Ascii or NoTTY. Detection picks one of them from the environment, and degradation only goes down. A TrueColor value is rewritten to the nearest color the chosen profile can show, and nothing is ever raised to a richer profile. Ascii drops the color and keeps decoration such as bold and underline. NoTTY strips every escape, so use it for streams that are not terminals.

What's in the box

Profile detectionOne canonical 14-step ladder every surface shares, override-first: CLICOLOR_FORCE=1 / FORCE_COLOR outrank every later leg (a falsy FORCE_COLOR spelling lands on the Ascii floor). Suppressors come next: NO_COLOR (empty = unset), CLICOLOR=0 and TERM=dumb (case-insensitive) turn color off — dumb outranks an advertised COLORTERM, it is a promise of minimal capabilities. Advertised depth follows: COLORTERM (24bit/truecolor, plus the legacy marker yes, which the ladder reads as a 256-color promise, not a 24-bit one), TERM_PROGRAM, WT_SESSION, GOOGLE_CLOUD_SHELL (exactly true grants TrueColor; any other value, false and 1 included, carries no 24-bit promise), the TMUX/STY + screen*/tmux* rung and the TERM depth patterns. Palette adds the stream TTY gate on top; Probe/AsyncProbe/TerminalProbe add the phase-2 infocmp Tc/RGB upgrade (a fixed-path binary, run with a minimal child environment). The detection ladder emits five levels (TrueColor, Ansi256, Ansi, Ascii and NoTTY), and the ColorProfile enum that carries the result has eight.
Color degradationPalette::toProfile() / Color::convert() downsample a color to the 256-color cube and gray ramp or to the 16 ANSI slots.
String rewritingdegrade() rewrites the SGR colors in a string for the current profile; under NoTTY it strips every escape — SGR, CSI, OSC and DCS sequences, SS3/APC/PM/SOS strings, the Fe escape pairs and charset selectors — decoration included, so pin the Ascii floor for a color-only strip. ProfileWriter does the same to everything written to a stream.
StandardColorsThe 16 ANSI colors as Color values via the non-mutating read API — StandardColors::all(), fromIndex(1), catalog(). (The $red/$brightBlack statics are deprecated process-global mutables; see the README deprecation window.)
Perceptual distanceCIELAB conversion with ΔE*76 / ΔE*94 / CIEDE2000 (DeltaE) and an opt-in nearest-palette matcher (NearestColor).

Detection phases

The capability probes run in four phases; phase 1 is the shared DetectionChain, so the ladder cannot drift between surfaces:

PhaseSourceWhat it can set
1 — env ladderDetectionChain over Env::resolve()Any of the five detection-emittable levels: TrueColor / Ansi256 / Ansi / Ascii / NoTTY
2 — terminfoinfocmp -1 at a fixed absolute-path roster, never looked up on PATHPromotes an Ansi/Ansi256 rung to TrueColor on Tc/RGB; Sixel from terminfo capability names
3 — advertisedTERM_PROGRAM capability map (interactive streams only)Advertised TrueColor (WezTerm/vscode/Ghostty), ITerm2 (iTerm.app), Hyperlinks (Hyper)
4 — floorsSuppression and minimal-capability floorsHolds the Ascii/NoTTY landings and the reserved-capability gates

The terminfo leg is an exec surface: the infocmp binary is launched from a fixed absolute-path roster (never looked up on PATH), and the child environment is built in one place — the queried TERM plus a fixed PATH only. TERMINFO, TERMINFO_DIRS and HOME each steer infocmp's database lookup and are never inherited. The parser's name-position guard protects the parse from a hostile terminfo entry but cannot vouch for the source: whoever can write the system terminfo directories owns that answer. Treat every detection result as a rendering hint, never as an authorization signal.

Tasks

Pin the profile for a test or a CI log. A non-empty $env replaces the ambient environment, so the answer is the same on every host.

use SugarCraft\ColorProfile\Palette;

$profile = Palette::detect(STDOUT, ['FORCE_COLOR' => '2']);
echo $profile->label();   // ANSI 256

Strip the color and keep the decoration. Pin the Ascii floor and run the string through degrade().

use SugarCraft\ColorProfile\{ColorProfile, Palette};

$plain = (new Palette())
    ->withProfile(ColorProfile::Ascii)
    ->degrade("\x1b[1;38;2;255;0;0mERROR\x1b[0m");
// "\x1b[1mERROR\x1b[0m": the bold stays and the color goes

Pin one stream to a rung. ProfileWriter::wrap() takes the same environment array, so every write to the stream degrades to that rung.

use SugarCraft\ColorProfile\ProfileWriter;

$writer = ProfileWriter::wrap(STDOUT, ['FORCE_COLOR' => '1']);
$writer->write("\x1b[38;2;255;0;0mdisk low\x1b[0m\n");   // written with the ANSI red, \x1b[91m

Configuration and options

Detection has no config file. The answer comes from the environment, and the host can pin it in code. The table lists the environment variables in ladder order. The first leg that matches wins.

Env varStepEffect
CLICOLOR_FORCE=11Forces TrueColor past every other variable, NO_COLOR included. It also keeps the forced rung on a non-TTY stream.
FORCE_COLOR2Sets the level: 3 or more gives TrueColor, and so do true, yes and on. 2 gives Ansi256, 1 gives Ansi. Any other spelling, such as 0 or false, lands on the Ascii floor.
NO_COLOR3A non-empty value gives the colorless Ascii rung. Color codes are dropped, and decoration such as bold and underline is kept.
CLICOLOR=04Suppresses color.
TERM=dumb5Suppresses color. It outranks COLORTERM.
TMUX / STY with screen*6Caps the level at Ansi256 before COLORTERM is read.
COLORTERM7truecolor or 24bit gives TrueColor. yes gives Ansi256.
TERM_PROGRAM=iTerm.app8Gives TrueColor. Matching is case-sensitive.
WT_SESSION9A non-empty value gives TrueColor (Windows Terminal).
GOOGLE_CLOUD_SHELL10Exactly true gives TrueColor.
TMUX / STY with tmux*11Caps the level at Ansi256, after COLORTERM is read.
TERM12–13*-256color, xterm-kitty and xterm-ghostty give Ansi256. xterm*, screen* and tmux* give Ansi.
REDUCE_MOTION / PREFERS_REDUCED_MOTION—Not part of the color ladder. A non-empty value other than 0, false, no or off sets Probe::reducedMotion().

A host that needs a fixed answer pins it with (new Palette())->withProfile(ColorProfile::Ansi). A Palette or TerminalProbe built with a non-empty $env array is hermetic: the array replaces the ambient environment, so pass every key the check reads. An empty array is not hermetic, and falls through to the process environment.

Keys and input

The library reads no keystrokes and binds no keys. Detection takes its input from the environment and the stream being written to. The optional probes add the output of a fixed-path infocmp run.

Theming and styling

Degradation is one-way. A TrueColor value can drop to Ansi256, Ansi or Ascii, but never rises. Palette::toProfile() and Color::convert() downsample one color, and degrade() rewrites every SGR color in a string. Under the NoTTY profile, degrade() strips all escape sequences, decoration included, so pin the Ascii floor for a color-only strip. The 16 ANSI colors come from StandardColors::all(), fromIndex() and catalog(). Opt into the perceptual family, NearestColor with DeltaE, when a degraded value must land on a fixed palette.

Troubleshooting and FAQ

Output is plain when the program is piped

That is the design. A stream with no TTY in front of it gets no color, so piping into a file stays safe to read. To keep color on a non-TTY stream, set CLICOLOR_FORCE=1. The force legs outrank the stream gate.

Color still appears with NO_COLOR set

CLICOLOR_FORCE and FORCE_COLOR outrank NO_COLOR. An exported force variable, from a shell alias or a CI image, can re-enable color for a user who set NO_COLOR. Unset the force variables, and check Probe::isNoColor() before you honor a force override.

A truecolor terminal reports Ansi256

Two legs cap the level. COLORTERM=yes is read as a 256-color promise, and a tmux or screen session caps the level at Ansi256. Set COLORTERM=truecolor where the terminal honors it, or let the phase-2 terminfo probe promote the rung when the entry advertises Tc or RGB.

An environment key is ignored

Env keys are matched case-exactly, so No_Color does not count as NO_COLOR. Windows reports its environment case-insensitively at the OS layer, so the same spelling can look set in a shell and still miss detection here. Use the exact spelling from the table.

Detection ignores the variables I did set

A non-empty $env array replaces the whole environment rather than overlaying it. Pass every key the check reads, or leave $env out so the process environment is used.

Upstream mapping

The port follows the concepts of charmbracelet/colorprofile: detect a profile from the environment, convert colors down to it, and wrap a writer so that output is downgraded to match. The mapping is behavioral. SugarCraft is developed as a native PHP project.

ConceptSugarCraftNotes

Color profile levelsColorProfile enumEight levels. The detection ladder emits five of them.
Color conversionColor::convert(), Palette::toProfile()One-way downsampling only.
Writer that downgrades outputProfileWriterApplies degrade() to everything written to a stream.
Perceptual distance (beyond detection)DeltaE, NearestColorOpt-in. Not needed for detection or degradation.

Architecture

DetectionChain is the one precedence core, and Env resolves and sanitizes the environment for it. Palette is the instance over that chain. It adds the stream TTY gate, and it does the degrading and stripping. The static Probe layer answers the questions that do not need an instance. AsyncProbe runs infocmp on a ReactPHP loop with bounded children, and Probe\TerminalProbe produces the phased report. The color math is ColorMath (sRGB to Lab), with DeltaE for the metrics and NearestColor for the matcher. ProfileWriter wraps a stream for automatic degradation.

Changelog and versioning

The library is pre-1.0, so consume dev-master. The mutable StandardColors statics are deprecated in favor of all(), fromIndex() and catalog(), and the Profile name is a deprecated alias for ColorProfile. The deprecation window is set out in the README.
