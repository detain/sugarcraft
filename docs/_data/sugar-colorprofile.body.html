Detect the terminal's color capability (NoTTY / Ascii / Ansi / Ansi256 / TrueColor) and degrade colors, strings and whole output streams to match it — one-way, TrueColor down, never up; an opt-in perceptual family picks the nearest palette color when a degraded value must land on a fixed set.

Install

composer require sugarcraft/sugar-colorprofile

Quickstart

use SugarCraft\ColorProfile\{Color, ColorProfile, Palette, ProfileWriter};

$profile = Palette::detect(STDOUT);      // ColorProfile::TrueColor | Ansi256 | Ansi | Ascii | NoTTY
echo $profile->label();                  // e.g. "No TTY" when piped

// Downsample one color to an explicit profile
$coral = Color::parse('#ff6b6b');        // r 255, g 107, b 107
$c256  = Palette::toProfile($coral, ColorProfile::Ansi256);
echo $c256->toAnsi256Index();            // 203
echo $c256->toAnsi256Foreground();       // "\x1b[38;5;203m"

// Rewrite every color in a string for a given profile
$ansi = (new Palette())->withProfile(ColorProfile::Ansi256)
    ->degrade("\x1b[38;2;255;107;107mhi\x1b[0m"); // "\x1b[38;5;203mhi\x1b[0m"

// Or wrap a stream and let it degrade (or strip, under NoTTY) on write
ProfileWriter::wrap(STDOUT)->write("\x1b[38;2;107;80;255mFancy\x1b[0m\n");

What's in the box

Profile detectionOne canonical 13-step ladder every surface shares, override-first: CLICOLOR_FORCE=1 / FORCE_COLOR outrank every later leg (a falsy FORCE_COLOR spelling lands on the Ascii floor). Suppressors come next: NO_COLOR (empty = unset), CLICOLOR=0 and TERM=dumb (case-insensitive) turn color off — dumb outranks an advertised COLORTERM, it is a promise of minimal capabilities. Advertised depth follows: COLORTERM, TERM_PROGRAM, WT_SESSION, GOOGLE_CLOUD_SHELL, the TMUX/STY + screen*/tmux* rung and the TERM depth patterns. Palette adds the stream TTY gate on top; Probe/AsyncProbe/TerminalProbe add the phase-2 infocmp Tc/RGB upgrade. The result is a ColorProfile: TrueColor, Ansi256, Ansi240, Ansi, Ansi8, Fgbg, Ascii or NoTTY.
Color degradationPalette::toProfile() / Color::convert() downsample a color to the 256-color cube and gray ramp or to the 16 ANSI slots.
String rewritingdegrade() rewrites the SGR colors in a string for the current profile and strips every escape under NoTTY. ProfileWriter does the same to everything written to a stream.
StandardColorsThe 16 ANSI colors as Color values via the non-mutating read API — StandardColors::all(), fromIndex(1), catalog(). (The $red/$brightBlack statics are deprecated process-global mutables; see the README deprecation window.)
Perceptual distanceCIELAB conversion with ΔE*76 / ΔE*94 / CIEDE2000 (DeltaE) and an opt-in nearest-palette matcher (NearestColor).

Detection phases

The capability probes run in four phases; phase 1 is the shared DetectionChain, so the ladder cannot drift between surfaces:

PhaseSourceWhat it can set
1 — env ladderDetectionChain over Env::resolve()Any of the five detection-emittable levels: TrueColor / Ansi256 / Ansi / Ascii / NoTTY
2 — terminfoinfocmp -1 at a fixed absolute-path roster, never looked up on PATHPromotes an Ansi/Ansi256 rung to TrueColor on Tc/RGB; Sixel from terminfo capability names
3 — advertisedTERM_PROGRAM capability map (interactive streams only)Advertised TrueColor (WezTerm/vscode/Ghostty), ITerm2 (iTerm.app), Hyperlinks (Hyper)
4 — floorsSuppression and minimal-capability floorsHolds the Ascii/NoTTY landings and the reserved-capability gates

Demos.

VHS-recorded GIFs of every example shipped with the library. Regenerated automatically on every push that touches the source.

Profile detection

Forced rungs print [TrueColor] -> "fancy" through [No TTY] -> "naughty!".

Standard colors

all() rows from 0 black #000000 to 15 brightWhite #ffffff, plus fromIndex() lookups.

Conversion

One hex, a different encoder per rung: \e[38;2;107;80;255m → \e[38;5;63m → \e[94m; No TTY strips.

Degrade

Same input written per rung: 38;2 → 38;5 → 91 → 97; the No TTY row prints [Orange] [Teal] [Purple] with no escapes.
