Fuzzy-search overlay: a render-and-state component your event loop drives — you decode keys and forward them (type(), cursorUp()/Down()); Enter is answered by the selected() query and hide() is the lifecycle call — neither is input the library consumes, it reads none itself. Composes into any SugarCraft app via the package-local Model contract. Supports structured Item objects, custom filter predicates, and persistent JSONL history.

Install

composer require sugarcraft/sugar-quickpick

Requirements: PHP 8.3+ with ext-ffi — the package hard-requires sugar-pty, which hard-requires FFI at install time even though only the opt-in attachSigwinch() path touches it (via SignalForwarder). ext-pcntl is needed only for that same attach; without it attachSigwinch() returns false and everything else works.

Stability: this package requires its sugarcraft/ siblings at dev-master. A Composer project left on the default stable minimum-stability cannot resolve them — add "minimum-stability": "dev", "prefer-stable": true to the consuming root (or pin the released sugarcraft/* tags once cut). The monorepo publishes all libs together, so sibling versions always line up.

Quickstart — plain strings

use SugarCraft\QuickPick\QuickPick;

$quickpick = QuickPick::new(
    items: ['Ruby', 'PHP', 'Go', 'Rust', 'Python'],
)->setPrompt('Choose language: ');

Quickstart — numbered items + history

use SugarCraft\QuickPick\QuickPick;
use SugarCraft\QuickPick\FilteredItem;
use SugarCraft\QuickPick\History\FileHistory;

$items = [
    new FilteredItem(1, 'apple'),
    new FilteredItem(2, 'banana'),
    new FilteredItem(3, 'cherry'),
];

$quickpick = QuickPick::new($items)
    ->setFilterFn(fn($item) => $item->number() > 0)
    ->setPrompt('> ');

// Persist selections (path you own; files created are 0600)
$history = new FileHistory(getenv('HOME') . '/.myapp/history.jsonl');
if ($choice = $quickpick->selected()) {
    $history->append($choice);
}
$allItems = $history->all();

What's in the box

Fuzzy matchingCase-folded substring filter; a candidate must match in the first half of the text (codepoint-based). setRanker() swaps in true subsequence scoring.
Composition wrapperupdate()/view() Model contract — package-local, no init()/subscriptions plumbing.
ConfigurableCustom formatter, prompt, match highlight style, window size.
Item interfaceStructured Item objects with number() + value() instead of raw strings.
Custom filter predicatessetFilterFn() applies arbitrary Closure(Item): bool logic.
Persistent historyFileHistory stores items as JSONL lines, one item per line.
Border & StylewithBorder() frames every row (T-junction separator); withStyle() paints each rendered row via sugar-style.
HelpBar / StatusBarKeyboard-shortcut summary and status message rendered below the overlay.
SIGWINCH resizewithOnResize() + attachSigwinch() forward terminal resize events via SignalForwarder.
