Month-grid date picker with keyboard navigation, min/max date constraints, localized day and month names (17 locales), and a fully-rendered ANSI view.

Install

composer require sugarcraft/sugar-datepicker

Quickstart

use SugarCraft\DatePicker\DatePicker;

// Opens on January 2026 with the cursor aimed at the seed date, 2026-01-15
// (a cursor on an empty cell falls back to the first valid day); every step
// returns a new picker.
$picker = DatePicker::new(new \DateTimeImmutable('2026-01-15'))
    ->handleKey(DatePicker::KEY_DOWN)   // one row down: Thursday the 22nd
    ->selectDate();                      // selects the date under the cursor

$picker->selectedDate()->format('Y-m-d');   // '2026-01-22'
echo $picker->view();                       // month grid, today and cursor highlighted

// Range mode: Enter sets the start, a second Enter the end
$range = DatePicker::new(new \DateTimeImmutable('2026-01-15'))
    ->withRangeMode(true)
    ->handleKey(DatePicker::KEY_DOWN)->handleKey(DatePicker::KEY_ENTER)
    ->handleKey(DatePicker::KEY_RIGHT)->handleKey(DatePicker::KEY_RIGHT)
    ->handleKey(DatePicker::KEY_ENTER);
[$range->rangeStart()->format('j'), $range->rangeEnd()->format('j')];   // ['22', '24']

What's in the box

Month gridA 6×7 month view with localized day and month names (17 locales), weeks starting Sunday (firstDayOfWeek is not configurable), today and the cursor highlighted, and optional ISO week numbers.
Keyboard navhandleKey() takes the KEY_* constants: arrows move the cursor, Home/End jump to the first/last selectable day of the viewed month (bounds consulted), PgUp/PgDn step one month, Enter selects (single mode) or sets the range start/end, Esc/Escape clears.
Range selectionwithRangeMode(true): the first Enter sets the start, the second the end (swapped if needed), a third starts over; Esc clears.
Date boundswithMinDate()/withMaxDate() clamp navigation to the allowed months and refuse out-of-range selection; withoutMinDate()/withoutMaxDate() lift a bound.
Host-owned colour policyThe widget emits raw SGR unconditionally; NO_COLOR stripping, attribute-only monochrome re-styling, and contrast alternates are documented host-side seams (README: Accessibility and terminal fallbacks).
SugarCraft modelModel wraps the picker as a sugar-core Model with an optional event store recording all eight published wire transitions (cursor_moved, month_changed, range_started, range_restarted, range_cleared, date_selected, date_cleared, selection_refused); the payload contract is in the README's Events section.
