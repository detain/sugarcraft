List view with box-drawing prefixes, cursor navigation, word-wrap, and live filtering (host-driven). It is a plain final class, not a TEA Model - render it from your host program's view() and feed it input there.

Install

composer require sugarcraft/sugar-treelist

Quickstart

use SugarCraft\TreeList\Model;

// Fluent setters return NEW Models - rebind. Data is immutable; view()
// mutates the delta-render memo in place, and withoutFilter() with no filter
// active is an identity return ($this, no clone).
// Model::tree() = new() + the Default prefixer/suffixer pair; plain new()
// stays deliberately undecorated, and withPrefixer()/withSuffixer() attach
// one half at a time (the set* spellings are deprecated aliases).
$model = Model::tree()
    ->withWidth(80)
    ->withHeight(24)
    ->withItemsFromArray(['src/main.php', 'src/Model.php', 'tests/MainTest.php']);

echo $model->view();
// Renders the list with a ╭ ├ ╰ box-drawing gutter chosen by item position
// (│ appears only as a wrap-continuation glyph), 1-based line numbers, and
// the cursor line decorated with the > … < marker pair

What's in the box

Box-drawing prefixesSwap in your own prefixer; the shipped one picks its glyph by item position (first / middle / last), not by nesting depth.
Cursor navigationUp / Down / Home / End movement with viewport tracking.
Word-wrapLong items wrap at the configured viewport width (setWidth) — the terminal is never auto-detected.
Filter state machinewithFilterFn() / withoutFilter() with FilterState enum (unfiltered / filtering).
Fuzzy matchingFuzzyMatch delegates scoring to sugar-fuzzy's SmithWatermanMatcher (SSOT).
Per-row delta repaintview() emits a full frame, then only changed rows as CUP + EL fragments; assistive hosts want lines() instead, or resetPreviousFrame() before every paint.

Accessibility

Guide the cursor with text, not color alone: keep a marker glyph ($currentMarker, or your suffixer's) so position survives monochrome terminals and screen readers — relying on withCurrentStyle()'s color by itself is a WCAG 1.4.1 (use of color) warning. withLineStyle('') + withCurrentStyle('') + lines() is the full plain-text mode: lines() never styles and never deltas, which makes it the right reader for assistive and scripted-output hosts.

The library emits no color of its own — every style is caller-supplied, so pass empty style strings to emit none; sugar-treelist neither reads nor acts on NO_COLOR. Item text all renders through the frame choke (Model::sweepForFrame), so content can forge neither a frame nor a click zone.
