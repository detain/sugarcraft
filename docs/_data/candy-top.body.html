A full-screen terminal system monitor in the spirit of btop, written in pure PHP on the SugarCraft stack: cpu, memory, network, disk and process panels drawn with braille graphs, gradient meters and btop's own themes, fed by Linux /proc + /sys collectors and driven by the CandyCore Model/Cmd runtime.

Status: scaffold, in progress. The package skeleton has landed; the rendering primitives it needs (dual-sample braille graphs, position-colored meters, border-embedded titles, the 101-stop gradient store) are being added to SugarDash, SugarCharts, SugarBits and CandySprinkles first, and the app is assembled on top of them.

Install

composer require sugarcraft/candy-top:@dev

What's planned

Six panelscpu (graphs, per-core grid, load / freq footer, battery + clock), mem + swap, net with autoscale, disk io, a sortable / filterable process list.
btop's drawing languageDual-sample braille and block graphs, 101-stop gradients, position-colored meters, titles embedded in the borders.
Linux collectorsInjectable-path readers for /proc/stat, meminfo, net/dev, diskstats, per-pid stats, thermal, hwmon and power-supply sysfs.
Themes + inputbtop's theme files ported as data; kitty keyboard + SGR mouse, vim keys, a btop-compatible config subset.
