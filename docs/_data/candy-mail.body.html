Email builder and sender. SMTP transport, Resend API transport, attachment support, HTML + plain-text multipart, and a fluent interface.

Install

composer require sugarcraft/candy-mail

Quickstart

use SugarCraft\Mail\{Email, ResendTransport, SmtpTransport};

// Immutable: every with*() returns a new Email
// Same headers as named arguments — new Email(from: ..., to: ..., subject: ..., body: ...) — read better when headers are optional
$email = Email::new('noreply@example.com', 'user@example.com', 'Deployment complete', 'Your app was deployed successfully.')
    ->withHtmlBody('<p>Your app was deployed <strong>successfully</strong>.</p>')
    ->withCc('ops@example.com')
    ->withAttachment('build.zip', '/tmp/build.zip');   // display name, then the file on disk

$transport = new SmtpTransport('smtp.example.com', 587, 'user', 'secret');
$transport->send($email);

// Or over the Resend HTTP API (key from the argument or RESEND_API_KEY)
(new ResendTransport())->send($email);

Attachment paths are read eagerly at build time — the file on disk must exist when withAttachment() is called, or the builder throws a RuntimeException.

What's in the box

SMTP transportTCP connection with TLS, auth (LOGIN via TLS, fail-closed).
Resend transportAPI-based sending via Resend.com — no SMTP needed.
AttachmentsLocal files, memory content, custom MIME types.
HTML + TextMultipart/alternative email bodies.
Command-line senderBody from stdin, repeatable address and attachment flags, offline --render preview.
