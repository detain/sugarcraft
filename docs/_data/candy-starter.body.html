composer create-project sugarcraft/candy-starter my-app — start from the template and you've got a working app. Demo Counter Model, PHPUnit wired up, bin/start entry point.

Install

composer create-project sugarcraft/candy-starter my-app

This package is type: project — composer create-project is the only install path. composer require refuses a project-type package, and would merge the skeleton's App\ autoloader map into your host app anyway.

Quickstart

composer create-project sugarcraft/candy-starter my-app
cd my-app
./bin/start

# Replace src/Counter.php with your own Model and keep editing.
my-app/
├── composer.json     # requires sugar-core + sugar-style
├── phpunit.xml
├── bin/start         # entry point — runs the Counter model
├── src/
│   └── Counter.php   # demo Model with up/down/quit, styled border
└── tests/
    ├── CounterTest.php                    # pinned behavior matrix
    ├── ModelContractDocumentationTest.php # README fence vs interface guard
    └── ReadmeSnippetsTest.php             # lints + runs every README php fence

API

ClassMethodDescription
Counterinit()Optional startup Cmd (null = none) — required method
Counterupdate(msg)Handle input message — returns [next Model, optional Cmd]
Counterview()Render the current frame
Countersubscriptions()Live Msg sources (null = none) — required method
Program (sugar-core)run()Start the app — provided by the sugar-core dependency, not shipped by the starter
