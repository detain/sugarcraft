The JSON Web Token and JSON Web Key handling that SugarCraft channel bundles need to verify signed tokens from a remote identity provider. Today the candy-msteams bundle carries its own copy of this code, and the non-bundle scripts/channel-bridge JwtValidator verifies tokens separately. This library is the planned single home for it. It is a skeleton: its namespace and packaging exist, and the verification classes arrive in a later change. There is no Charmbracelet upstream; this library is first-party.

Install

composer require sugarcraft/sugar-jwt

Requires PHP 8.3 or newer. The package has no runtime dependencies beyond PHP.

Status

The package currently ships only its PSR-4 wiring under SugarCraft\Jwt\. No public API exists yet, so there is no quickstart to show. The candy-msteams bundle keeps its own token and key-set code, and scripts/channel-bridge keeps its JwtValidator, until the verifier lands here.
