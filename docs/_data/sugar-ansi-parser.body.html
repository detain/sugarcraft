Parse ANSI escape sequences into structured events (SGR attributes, cursor movement, erase operations, DEC private modes, OSC and DCS strings) without coupling the parser to any cell grid. SugarAnsiParser is the VT500 byte-stream state machine behind sugar-vterm, extracted so other consumers can share it. It follows the Paul Williams DEC parser diagram and mirrors the parser side of charmbracelet/x/ansi.

Install

composer require sugarcraft/sugar-ansi-parser

Requires PHP ^8.3. ext-mbstring is a suggestion, not a requirement: it is consulted only by the $replaceMalformed = true UTF-8 mode. Default parsing never touches it, and constructing the parser with that flag but without the extension fails at the constructor, not in the middle of a stream.

Quickstart

use SugarCraft\AnsiParser\Parser\{DebugHandler, Parser};

$handler = new DebugHandler();          // records every parse action
$parser  = new Parser($handler);

// Chunks may split anywhere; in-flight sequences carry across feed() calls.
$parser->feed("\x1b[1;");
$parser->feed("31mHi\x1b[0m");
$parser->flush();                        // end of stream: dispatches a pending string payload

$handler->filter('csi');   // two csi entries: params [1, 31] then [0], final 'm' (109)
$handler->filter('print'); // rows with detail 'H', 'i'

To drive a cell grid, implement CsiHandler (cursor, erase, scroll, SGR, DEC modes) and OscHandler (title, hyperlink), then bridge them to the parser:

use SugarCraft\AnsiParser\Parser\{HandlerAdapter, Parser};

$parser = new Parser(new HandlerAdapter($myCsiHandler, $myOscHandler));
$parser->parseComplete($bytes);          // feed() + flush() in one call

Concepts

The parser is a state machine over bytes. It recognises where a control sequence starts and ends, and it hands each complete piece to a handler as an event: a printed rune, a C0 control, a CSI or ESC dispatch, an OSC or DCS string. It does not decide what those events mean. Screen state, cell grids and cluster assembly belong to the consumer, which is why this package stops at abstract events.

There are two ways to consume events. A consumer that wants every byte-level event implements the seven-method Handler interface. A consumer that wants the cursor, erase, SGR and mode semantics implements CsiHandler and OscHandler and receives them through HandlerAdapter, which is a deliberate sieve: it passes only the events those interfaces describe, and a $fallback handler can take the rest.

Common tasks

Feed a stream in chunks. Sequences and UTF-8 runes split across feed() calls are reassembled. Call flush() once at the end so a pending string payload is dispatched:

$parser = new Parser($handler);
foreach ($chunks as $chunk) {
    $parser->feed($chunk);
}
$parser->flush();

Read colon-separated subparameters. CSI 4:3 m is curly underline, one slot with a subparameter, and it is not the same as CSI 4;3 m. subparams() reports which slots carry a colon, and groupSubparameters() regroups them:

$grouped = Parser::groupSubparameters($params, $parser->subparams());
// $grouped is a list of lists, one inner list per slot

Decode an OSC 8 hyperlink. A hyperlink open carries a URI, and a close is an empty URI. HandlerAdapter reports both through OscHandler::hyperlink(), and it accepts the backtick-terminated form as well:

use SugarCraft\AnsiParser\Parser\{HandlerAdapter, Parser, RecordingOscHandler};

$osc = new RecordingOscHandler();
$parser = new Parser(new HandlerAdapter($csi, $osc));
$parser->parseComplete("\x1b]8;;https://example.org\x1b\\link\x1b]8;;\x1b\\");
$osc->hyperlinkUri(); // the URI of the currently open link

Bound a long-lived log. DebugHandler keeps an unbounded $log by default, which suits test fixtures. For a long-lived mirror, pass maxLogRows and the log becomes a keep-newest ring that counts evictions in $dropped:

$debug = new DebugHandler(maxLogRows: 500);
$parser = new Parser($debug);

Decode an inline image payload. The codecs parse the payloads of DCS, iTerm2 OSC 1337 and Kitty APC sequences into typed objects, and they report malformed input instead of guessing:

use SugarCraft\AnsiParser\Codec\Iterm1337;

$file = Iterm1337::parse($payload);   // ?Iterm1337, null when the payload is not OSC 1337
if ($file !== null && $file->isFile()) {
    $declared = $file->declaredSize();
}

What's in the box

VT500 state machineParser implements the Paul Williams DEC parser and dispatches abstract Handler events: printChar, execute, csiDispatch, escDispatch, oscDispatch, dcsDispatch and sosPmApcDispatch.
Partial-input safeFeed any chunk size. Incomplete sequences and UTF-8 runes wait for the next feed(). flush() (or parseComplete()) settles a pending OSC, DCS, SOS, PM or APC string at end of stream. An in-flight CSI or ESC, and a half-finished DCS prelude, end undispatched.
CSI handler interfaceCsiHandler covers the renderer's working CSI set, plus CR and LF routed from C0 executes: CUU/CUD/CUF/CUB/CUP/HVP, ED/EL, SU/SD, IL/DL, ICH/DCH, REP, SCO save and restore, DECSET/DECRST, DECSTBM, TBC/CHT/CBT and SGR. HandlerAdapter translates parser events into these calls.
Sub-parameterssubparams() and Parser::groupSubparameters() keep ECMA-48 colon groups apart, so CSI 4:3 m (curly underline) is not confused with CSI 4;3 m. Handlers can opt in through SubparamsAwareHandler.
Bounded payloadsDCS, OSC, SOS, PM and APC payloads are capped at 64 KiB by default. The third constructor argument changes the cap, and any positive value is accepted. Past the cap the excess is dropped, and stringOverflowed() reports it for the dispatch that carries it.
DebugHandlerA development mirror that records every action as ['type' => …, 'detail' => …] rows. Pass maxLogRows: for a long-lived mirror. filter($type) selects one kind, and resetLog() clears the rows and the eviction counter together.
Null sinkNullHandler consumes every event and does nothing. Its seven counter accessors, from printCount() to sosPmApcCount(), keep even a silent sink observable.
Recording doublesSupport\RecordingCsiHandler is a final recording double that ships in src/, so interface growth breaks it at compile time instead of silently drifting a hand-rolled stub. RecordingOscHandler stores the window title and tracks the current hyperlink pair.

Subparameters and multi-mode dispatch

ECMA-48 separates parameter slots with ; and subparameters with :. CSI 4:3 m is one slot with a subparameter, and CSI ? 1000 ; 1006 h sets two modes. The parser exposes both faithfully. subparams() returns, for each dispatch, a list of flags aligned with $params, with true at each index whose value was followed by a colon. The flags follow the upstream Go Param.HasMore design, so SGR consumers can handle colon forms such as 58:2::148:199:255 without re-splitting the stream.

HandlerAdapter dispatches every parameter of CSI h and CSI l as a separate decset() or decrst() call, preserving the prefix. The parser flags the colon structure but does not interpret it, so a handler that ignores subparams() keeps the semicolon-split view of $params.

Examples

  • examples/debug.php: walks one stream per Handler event family, covering print and CSI, execute, ESC, OSC, OSC 8 raw payloads, DCS, APC and the C1 introducers. It prints each event as the parser reports it.
  • examples/adapter.php: drives HandlerAdapter itself. It shows the DECSET fan-out, the OSC 8 open and close pair, and the sieve with and without its $fallback.
php examples/debug.php
php examples/adapter.php

Testing

Run the suite from the library root with PHPUnit 10:

cd sugar-ansi-parser && composer install && vendor/bin/phpunit

The tests are organised by component. ParserTest.php and TransitionsTest.php cover the state machine, HandlerAdapterTest.php, HandlerAdapterModeDispatchTest.php and HandlerAdapterFallbackTest.php cover the adapter, SgrSubparameterTest.php covers colon forms, and ParserOverflowTest.php and DcsTruncationTest.php pin the payload caps. The Codec/ directory holds the decoder tests.

Troubleshooting

SymptomCause and fix
A final CSI or ESC at the end of the stream never dispatchesflush() and parseComplete() settle only string payloads. An in-flight CSI or ESC cannot be recovered, so it ends undispatched. Make sure the producer sends complete sequences.
An OSC or DCS payload arrives truncatedPayloads cap at 64 KiB by default. Call stringOverflowed() inside the dispatch to detect the cut, or raise the cap with the third constructor argument.
Invalid UTF-8 causes an error or a garbled runePass replaceMalformed: true to turn malformed sequences into U+FFFD. The flag needs ext-mbstring, and the constructor fails loudly when the extension is missing.
A fallback handler receives nothing for ESC, DCS or the C1 bandHandlerAdapter is a sieve. It drops the whole ESC family, DCS, SOS, PM and APC payloads, and every execute except HT, LF, CR and BS. Pass the events to a $fallback handler, or implement Handler directly.
Colon-separated colour arguments arrive as separate valuesThe parser flags the structure but does not interpret it. Read subparams() during the dispatch, or implement SubparamsAwareHandler. groupSubparameters() regroups them.
A DebugHandler log grows without boundThe default log is unbounded, which suits fixtures. Pass maxLogRows for a long-lived mirror.

Limits and hostile input

The parser is built for untrusted byte streams. Its bounds are part of the product. Payloads are capped as described above, so a hostile stream cannot grow the buffers without limit. The codecs report malformed input instead of guessing. Dropped bytes are signalled, not silent: the overflow flag, the truncation flags on the codecs, and the $dropped counter of a bounded DebugHandler all say when information was lost.
