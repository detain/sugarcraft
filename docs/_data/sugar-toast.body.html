Non-blocking floating notifications at 9 screen positions. Error, Warning, Info, Success types. Auto-dismiss, an Escape-dismiss preference flag for hosts, and stacked multi-toast support.

Install

composer require sugarcraft/sugar-toast

Quickstart

use SugarCraft\Toast\{Position, Toast, ToastType};

$toast = Toast::new(50)  // max width 50
    ->withPosition(Position::TopRight)
    ->withDuration(10.0);  // seconds

$toast = $toast->alert(ToastType::Success, 'File saved!');
$toast = $toast->alert(ToastType::Error, 'Connection failed');

$bg = str_repeat("background content\n", 20);
echo $toast->view($bg);

What's in the box

Four typesError, Warning, Info, Success — each with a distinct symbol and color.
Positions9 positions: TopLeft, TopCenter, TopRight, BottomLeft, BottomCenter, BottomRight, MiddleLeft, MiddleCenter, MiddleRight.
Auto-dismissConfigurable duration. Passing null $expiresAt at the alert()/progressToast() doors means "use the configured duration" — persistence is reached by keeping the toast duration unset or through the explicit sentinel (withoutExpiry()/cancelAlert()).
Symbol setsNerdFont, Unicode, or Ascii.
Overflow controlDropOldest, DropNewest, or Enqueue when maxConcurrent is exceeded.
Progress toastsInline progress bar beneath the message body — by default the bar speaks in glyph and colour; the numeric percentage (0–100%) prints only under withAccessibleText().
Action buttons[Label] buttons with closure callbacks; their frame cells are exported by actionRects()/actionAt() for host-side mouse and keyboard dispatch.
History logCumulative immutable record of dismissed and overflow-evicted alerts via history(); clear() never resets it.
Styled alertsPer-alert background, foreground, and border colour overrides via Color.

Langt(key, params)Translate a string: 'dismiss', 'count', 'type.*'. The library itself renders only the type.* labels (via ToastType::label()); dismiss/count are convenience strings for host UI and are never emitted by view().

Per-alert render size is bounded too: Toast::MAX_MESSAGE_CELLS truncates over-long messages with a visible marker and Toast::MAX_ACTIONS_PER_ALERT folds surplus buttons into a "[+N more]" row — the full text and action list still ride the Alert into history.

Trust boundary. In a TUI the terminal is a sink: alert text is composited through the cell grid, so raw ESC/OSC/BEL payloads in a message never reach the output stream — only SGR the renderer itself builds does. Inline SGR in a message is honoured as styling, so sanitise attacker-authored text (Sanitize::untrusted()) before enqueueing. sugar-mouse PUA zone markers (U+E000/U+E001) in toast text pass through as ordinary glyphs — hosts parsing marked frames must sweep with Sanitize::untrustedForMarkedFrames(); the host's own markers on a marked background frame, and its OSC-8 link runs on rows the toast does not cover, survive compositing. Full contract: docs/TRUST-BOUNDARY.md §1.

Internationalization

User-facing strings use SugarCraft\Toast\Lang::t(). All keys live as bare entries in lang/en.php; the toast lookup namespace is baked into src/Lang.php, not a nesting level inside the arrays.

KeyDefaultParameters
type.info / type.warning / type.error / type.successInfo / Warning / Error / Success—
dismissPress any key to dismiss—
count{count} notification(s){count}

To localize, copy lang/en.php to lang/<code>.php and translate the values.
