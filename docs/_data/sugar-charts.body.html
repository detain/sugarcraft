Sparkline, Bar, Line, Heatmap, Scatter, TimeSeries, Streamline, Waveline, OHLC, plus inline image rendering via Sixel / Kitty / iTerm2 protocols. Picture output routes on TERM / TERM_PROGRAM; everything else is explicitly configured.

Install

composer require sugarcraft/sugar-charts:dev-master

No tagged releases ship yet — Packagist serves the dev-master branch only, so name it explicitly; on a default-stable project a bare sugarcraft/sugar-charts request does not resolve.

Quickstart

use SugarCraft\Charts\Sparkline\Sparkline;
use SugarCraft\Charts\BarChart\BarChart;
use SugarCraft\Charts\LineChart\LineChart;

echo Sparkline::new([1, 3, 2, 8, 5, 4, 7, 6], 8)->view() . PHP_EOL;
// " ▂▁█▅▃▇▆" (scaled to the window's min..max; the minimum is a blank cell)

echo BarChart::new(
    [['cpu', 0.7], ['mem', 0.4], ['disk', 0.9]], 20, 5
)->view() . PHP_EOL;

echo LineChart::new([1, 4, 2, 8, 6, 3, 7], 30, 6)->view();

What's in the box

CanvasFixed cell grid with per-cell runes and sugar-style Style. Foundation for the grid renderers (LineChart, Heatmap, Scatter, OHLCChart, Waveline); Sparkline builds on sugar-cellbuffer and Picture emits raw protocol bytes.
SparklineSingle-row series via 8 Unicode bar glyphs. Perfect for log dashboards.
Bar / LineAuto-scaling y-axis, configurable axis labels, annotation and area knobs: withMarkLines(), withFill(), withFractionalHeights().
HeatmapDensity visualisation with palette gradients.
OHLCCandlestick chart for financial time-series.
TimeSeriesTimestamped [DateTimeImmutable, value] tuples rendered through LineChart with time-range windowing; pre-aggregate with the Aggregation toolbox when points share a timestamp.
Streamline / AggregationSliding-window streaming chart (fixed-capacity ring buffer, append-only), plus bucket-by-time, moving-average, and resample aggregators.
Picture (Sixel/Kitty/iTerm2)Inline raster image rendering; detect() routes on TERM / TERM_PROGRAM (best-effort env sniffing, not a terminal query). When no protocol is detected, view() prints a plain-text placeholder — withProtocol() overrides the choice.
Per-point / per-bar colorbtop-style value heat: LineChart::withSeriesColorFn() and BarChart::withBarColor() resolvers.

Per-point and per-bar colors

btop tints every graph point and meter by its value through the theme gradient. LineChart::withSeriesColorFn(fn(string $dataset, int $x, float $value): ?Color) colors each sample's dot, fill run and outgoing connector ($dataset is LineChart::PRIMARY_SERIES for the unnamed series; $x is the index in the full series; null keeps the series color). BarChart::withBarColor(fn(Bar $bar, int $i): ?Color) colors each bar's body and eighth-block cap. Passing null restores byte-identical default output; a non-Color return throws UnexpectedValueException.

use SugarCraft\Charts\BarChart\{Bar, BarChart};
use SugarCraft\Charts\LineChart\LineChart;
use SugarCraft\Core\Util\Color;

$heat = static fn (float $v): Color => match (true) {
    $v >= 7 => Color::hex('#ff5555'),
    $v >= 4 => Color::hex('#f1fa8c'),
    default => Color::hex('#50fa7b'),
};

echo LineChart::new([1, 4, 2, 8, 6, 3, 7], 30, 6)
    ->withSeriesColorFn(
        static fn (string $dataset, int $x, float $v): ?Color =>
            $dataset === LineChart::PRIMARY_SERIES ? $heat($v) : null,
    )
    ->view() . PHP_EOL;

echo BarChart::new([['cpu', 0.7], ['mem', 0.4], ['disk', 0.9]], 20, 5)
    ->withFractionalHeights()
    ->withBarColor(static fn (Bar $bar, int $i): ?Color => $heat($bar->value * 10))
    ->view() . PHP_EOL;
