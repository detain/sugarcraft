The test harness SugarCraft pioneered: ProgramSimulator for driving SugarCraft apps with scripted input, Assertions for golden-file and cell-grid snapshots, and TapeRecorder for composing VHS demo scripts.

Install

composer require --dev sugarcraft/sugar-testing:@dev

This is a PHPUnit test harness: it belongs in require-dev and must not enter runtime dependencies.

Quickstart

use SugarCraft\Testing\ProgramSimulator;
use SugarCraft\Testing\Input\ScriptedInput;
use SugarCraft\Testing\Snapshot\Assertions;

// Script terminal input: keys, plus a bracketed paste decoded by sugar-core's
// real InputReader (sanitized by default, as at runtime).
$script = ScriptedInput::new()
    ->key('+')
    ->key('+')
    ->paste("hello\n")
    ->enter();

$sim = ProgramSimulator::for(new Counter());   // a Model or a Program
foreach ($script->build() as $msg) {
    $sim->send($msg);
}
$result = $sim->run();                         // TestResult: model, view, cmds, output

Assertions::assertGoldenAnsi(__DIR__ . '/fixtures/counter.golden', $result->view);
echo "Final count: " . $result->model->count();

ProgramSimulator

for(Model|Program)Factory: wrap a Program, or a bare Model in a default Program, for deterministic testing.
send(Msg)Fluent message enqueue — chain multiple sends.
withFakeCmdRunner()Decide the message injected for each Cmd; the real closure still runs unless you also call withRealCmdRunner(false).
run()Drain the queue, return TestResult with model/view/cmds/output. Subscription output is delivered right after the message that triggered it; messages still queued when a QuitMsg/InterruptMsg halts the drain are skipped and counted in droppedAfterStop. run() can be called again.

ScriptedInput

key() / namedKey() / enter() / arrow() / mouse() / resize() / ticks()Fluent builders for the messages a session produces; build() returns the list.
bytes(...$reads)Raw terminal input parsed by sugar-core's real InputReader, one argument per read (split into 4096-byte reads like the runtime), with the runtime's idle recovery afterwards: a lone ESC becomes an Escape key and an unterminated paste is closed.
paste(content)A bracketed paste sent through bytes(), so the model sees the same PasteStartMsg, PasteEndMsg, PasteMsg sequence as at runtime (longer pastes arrive in several PasteMsg chunks).
withSanitizePaste(bool)Pasted payloads are sanitized by default, as at runtime; pass false to deliver them verbatim. Call it before bytes().

Assertions

assertGoldenAnsiByte-exact snapshot test — set SUGAR_TESTING_UPDATE_GOLDENS=1 (legacy alias: UPDATE_GOLDENS=1) to create a missing golden; creation is one-way and a mismatch never rewrites, so to re-baseline, delete the file and rerun with it set.
assertCellGridCell-by-cell diff for Buffer-based renderers.
assertAnsiEqualsByte-exact ANSI comparison with readable ESC diff.

TapeRecorder

to(path)Factory: start a script builder whose save() writes the tape to the given path.
header()Write VHS header (theme, font size, width, height).
type() / enter() / sleep()Append the demo's choreography — Type/Enter/Sleep directive lines; nothing is captured from a running program and there is no playback API.
save()Write the completed .tape file.

Use it for

  • Deterministic Model–Update–View testing — ProgramSimulator drives Programs without real I/O.
  • Snapshot regression testing — Golden files for ANSI output.
  • Cell-grid assertions — assertCellGrid for Buffer-based renderers.
  • Demo script building — TapeRecorder emits VHS-compatible .tape files; CI renders them into GIFs.
  • Test-infra hub for 22 sibling packages — incl. sugar-forms and sugar-widgets, which build their test support on it (census: sibling composer.json require/require-dev at commit time).
