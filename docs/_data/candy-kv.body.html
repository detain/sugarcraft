Personal key/value store — one SQLite database per store, @dbname namespaces, glob listing, TTL, binary values, JSON/YAML import/export, and a bare CLI.

Install

composer require sugarcraft/candy-kv

Quickstart

use SugarCraft\Kv\Store;

$store = new Store();                       // SQLite files under ~/.config/skate

$store->set('user:1', 'Alice');
$store->set('user:2', 'Bob');
echo $store->get('user:1');                 // 'Alice'
echo $store->get('missing', 'n/a');         // fallback: 'n/a'

// A key@db suffix routes to a named database ("\@" spells a literal at-sign)
$store->set('token@passwords', 'ghp_xxxx');
$store->setWithTtl('session', 'abc', 60);   // expires after 60 s

foreach ($store->list('user:*') as $entry) {  // byte-exact glob patterns; yields Entry
    echo "{$entry->key} => {$entry->rawValue()}\n";
}
$store->listDatabases();                    // ['default', 'passwords']
$store->pruneExpired();                     // reclaims expired rows in the default database

CLI

candy-kv set color blue              # values with NUL/invalid UTF-8 auto-arm binary mode
candy-kv get color                   # prints exact stored bytes, no added newline
candy-kv list 'user-*'               # key<TAB>value rows; binary values show a <binary N bytes> placeholder
candy-kv delete 'tmp-*' --dry-run    # preview the match count without writing
candy-kv prune                       # remove expired residue
candy-kv export json > backup.json
candy-kv import json backup.json     # atomic across databases by default

Exit codes: 0 success, 1 miss / no match / runtime failure, 2 usage errors (unknown flags and commands are refused before anything is written). Run candy-kv --help for the full flag list.

What's in the box

SQLite storageOne SQLite file per named database under the data directory (~/.config/skate by default, files at 0600); key@db picks the database and reads never create files.
Glob and fuzzy listingCase-sensitive * / ? glob patterns (\* spells a literal star), reverse order, keys-only or values-only modes, and fuzzyFilter().
TTL supportExpire keys after a set time; expired rows are invisible to readers immediately and stay on disk until pruneExpired() reclaims them.
Binary values and transactionsStore raw bytes as binary entries (rawValue() decodes them) and group writes in a transaction.
