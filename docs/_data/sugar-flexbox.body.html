FlexBox layout engine for terminal grids — ratio-based item sizing, gap, align. Plus a simple table with sort, filter, cursor nav, and column styling. Viewport and Scrollbar compose the sugar-widgets SSOT.

Install

composer require sugarcraft/sugar-flexbox

Quickstart

use SugarCraft\Flexbox\Flex\{FlexBox, FlexItem};
use SugarCraft\Flexbox\Table\{Table, Column};

$flex = FlexBox::row(
    FlexItem::new('LEFT')->withRatio(1),
    FlexItem::new('RIGHT')->withRatio(2),
)->withGap(2);

$table = (new Table())
    ->addColumn(Column::make('Name', 20))
    ->addRow(['Alice'])
    ->addRow(['Bob'])
    ->sortBy(0, true);

echo $flex->render(40, 1), PHP_EOL;
echo $table->render(), PHP_EOL;

What's in the box

FlexBoxRatio-based row / column layout. Align: Start, Center, End, Stretch (one value drives both axes — box height plus text placement in row mode, rendered width plus placement in column mode; no CSS justify-content counterpart).
TableSort by column (asc/desc toggle), filter by text, cursor navigation, per-column style.
ViewportScrollable viewport composes sugar-widgets Viewport (SSOT). Keyboard nav (line/page/half-page), mouse wheel, smooth scroll, scrollbar. Sticky headers and footers via withStickyHeader()/withStickyFooter(); syncWith() is a decorative partner marker only (scroll state never propagates).
ScrollbarScrollbar composes sugar-widgets Scrollbar (SSOT). Vertical/horizontal, configurable thumb/track chars.
ImmutabilityAll builders return new instances.

Trust boundary

Table, Column and FlexBox treat everything they render as untrusted data: cell values and column titles pass through Sanitize::untrusted(), and newlines, tabs and carriage returns are replaced with spaces at render time, so no escape sequence can ride in through content. Style strings are gated to legal SGR parameter text (codes 0..255 separated by single ;) or empty for no style; anything else throws InvalidArgumentException naming the refused property. Viewport and Scrollbar are trusted-input by design — the Viewport renders your withContent() lines as given and the Scrollbar emits your runes verbatim — so sanitize user input before feeding them. The FlexBox measures an item's raw content before the render-time sweep, so control bytes still consume measured cells even though the printed frame carries the swept text.
