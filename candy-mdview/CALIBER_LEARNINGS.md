- **[pattern:glow]** ~~WidthHelper uses `mb_strwidth('UTF-8')` for all width calculations.~~ STALE since the canonical-helper migration: candy-mdview's WidthHelper was DELETED — the canonical measurer is `SugarCraft\Core\Util\Width` (`Width::string()` raw cells, `Width::of()` ANSI-stripped cells; CJK/emoji cost 2, combining marks 0). Never use `strlen()`/`mb_strlen()` for visual width, and never re-add an mdview-local copy — `WidthPlumbingTest::testNoMdViewLocalWidthHelperIsResurrected` guards it.
- **[pattern:glow]** FileWatcher::watch() is a Generator that runs indefinitely. Always consume it inside a loop with a termination condition or stream context cancellation — never `foreach` it directly outside a coroutine dispatcher or you will block forever. Since the TEA polling rework the stateless pair `FileWatcher::snapshot()` / `FileWatcher::pollTuple()` (mtime+size tuple, `[0,0]` = absent sentinel) is the building block for TEA-style polling — `MdViewModel::withWatch()` drives the pager's auto-reload with one `Cmd::tick(self::RELOAD_POLL_SECONDS)` re-armed per handled `ReloadTickMsg` (sweep returns `$this` identity when unchanged so the Model stays value-stable).
- **[pattern:glow]** `--theme-config` accepts both schemas: a top-level `"document"` object marks glamour JSON (`GlamourTheme::isGlamourSchema`) and is projected onto SugarMarkdown `Theme`; otherwise the historic flat map goes to `Theme::fromJsonString`. Glamour chroma resolves EXACT base token before first prefix-subtype (Keyword beats KeywordType); colour vocab folds 0-15 indices to plain SGR via `Color::ansi256`, hex throws on malformed.
- **[pattern:assert-golden-ansi]** Use `assertGoldenAnsi` for any new `render()` test. Fixture files live in `tests/fixtures/` with a `.golden` extension. Re-record goldens with `UPDATE_GOLDENS=1 vendor/bin/phpunit` after intentional output changes. Mirrors: `docs/old/repo_map_step_28.md`.
- **[rule:step-29]** Don't call `getenv()` or read terminfo directly for terminal capability probing — go through `\SugarCraft\ColorProfile\Probe\TerminalProbe::run()` and handle `\Throwable` gracefully (fall back to lowest-common-denominator rendering). RenderCommand demonstrates the pattern with a defensive `terminalSupportsColor()` wrapper, consulted only after the environment verdict in `decoratedOutput()` (NO_COLOR/CLICOLOR/CLICOLOR_FORCE/FORCE_COLOR) — an env answer never reaches the probe.

- Lang class now extends `SugarCraft\Core\I18n\Lang` — `t()` method inherited from base; NAMESPACE and DIR are the only per-lib constants.
- **[rule:MDV-S18]** `MdViewModel` keeps its own typed-override `mutate()` map (renamed from `copy()` 2026-11-13) instead of sugar-core's `Concerns\Mutable`: the model carries closures and a `?string` watch path where null IS the meaning, so the bool-XSet sentinel law has nothing to pair.
