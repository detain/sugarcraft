## Background (why this step exists)

The compaction prompt today asks for ONE line per exchange under 200 characters
(`src/Chat.php:9022`, `:9030`), and the parse (`parseExchangeSummaries :9426-9445`)
maps numbered single lines positionally onto exchange keys. The plan (:2718-2720)
records what that format loses: file paths, decisions taken, user corrections, exact
error strings. P8.S1 replaces the FORMAT (prompt text + parse contract) with a
six-facet per-exchange RECORD — `asked:/did:/files:/decided:/corrected:/error:` —
while keeping the transport (`array<string,string>` keyed by exchange hash), the
positional keying, the degrade-not-misattribute fallback, and every surrounding
method byte-unchanged. NO method restructure is permitted by this step.
