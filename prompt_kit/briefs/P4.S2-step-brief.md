## §1.11 — WHAT COUNTS AS A TEST HERE. READ THIS TWICE.

These do **not** count: annotations (`@covers`, `@test`); existence checks (`method_exists()`,
`class_exists()`, `is_callable()`, `property_exists()`); shape assertions (`assertNotNull`,
`assertIsArray`, `assertTrue(count(...) > 0)`). A real test calls the thing, asserts the **value**
and **exact counts**, covers **both polarities** + **pathological input**, goes red when reverted.

**Deletion experiments this step MUST run and report** (each: exact revert edit, command, red test
name and count, restoration confirmed):

- Removing **any single bucket assignment** in any provider's usage parse must **RED that
  provider's UsageWiringTest case** — per provider, per bucket that provider actually parses.
- For a provider recorded as **no-cache-field**: planting a cache field into the as-received
  fixture must **NOT crash the parser** — decide the honest behaviour and **pin it with a test**.

An unstated or unrun deletion experiment fails the step regardless of how green the suite is.
