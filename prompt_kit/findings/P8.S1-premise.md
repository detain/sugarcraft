## Orchestrator rulings (binding)

- **P8.S1-D1**: format = per-exchange structured RECORD (numbered block with six
  facet lines `asked:/did:/files:/decided:/corrected:/error:`, `none` mandatory for
  empty), NOT a whole-conversation document. Rationale: document-level summaries
  would require splicing surgery in ContextCompactor/applyModelCompaction = the
  forbidden restructure; the record form carries everything the plan names as lost
  (paths, decisions, user corrections, exact error strings — plan :2718-2720), keeps
  `array<string,string>` transport + heuristic fallback byte-unchanged, and leaves
  P8.S3's `<prior-summary>` recursion cleanly layered.
- **P8.S1-D2**: `SUMMARY_LINE_MAX_CHARS` 200 → 2,000 with an honest rewritten
  docblock (transport protection, flattening rationale; NO LONGER a "matches the
  prompt ask" claim since the prompt stops stating 200). Both bounds must agree on
  the new reality.
- **P8.S1-D3**: parse must accept a block ONLY if it opens with a bare numbered line
  (`1.` alone); facets absent inside a recognized block fill `none`; a block with
  ZERO recognized facets + zero continuation lines stays UNMAPPED (heuristic).
  Legacy `1. text-on-same-line` output must NOT be half-parsed — model obeying the
  new template is the contract.
