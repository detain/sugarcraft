## Per-step notes

**O-0 spikes.** (a) react/http + rfc6455 echo server on `Loop::get()` beside a live `completeAsync()` turn, under both StreamSelect and ext-uv; (b) fork/COW cost with 30 loaded hosts; (c) a turn child closing inherited listener/client fds (`/proc/<pid>/fd`); (d) optional candy-core `Program::start()` (non-blocking, no terminal; candy-core has no such API, `Program::run()` at :335 owns the loop). The output is a findings note, not code. Pin `ratchet/rfc6455 ^0.4` + psr7 factory compatibility here.

**O-1x (beyond 1.C).** Roadmap 1.C names the frames `permission_request/permission_reply/steer/cancel_tool/mailbox`. 14 §5.1 also needs: `step` and per-step `usage` frames (usage arrives only in `result` today); `steer_ack`; `cancel_soft`; `askId` bound to a hash of `{toolCallId, tool, arguments}`; and a `PendingAsk` handle any consumer can answer (not only the Chat inbox) that resolves `cancelled` on teardown. **Decide one frame vocabulary before 1.C ships.** Recommended: 14's `ask/ask_reply`, with 1.C's names as aliases. Otherwise O-3b inherits a rename.

**O-2 (strangler, sequential a→h).** Each sub-step lands "Chat now calls X" in the same PR, and Chat's tests are the regression net. Risk: 33 test files reflect Chat privates (e.g. `scheduleParkedCompaction`, `estimateTokenCount`, `persistTranscript`, `dispatchCommand`, `budgetStatusLine`, `sanitizeSessionTitle`, `turnHookContext`), and 22 read `src/Chat.php` source text. Keep thin delegating Chat methods with the same names where a test or doc cites them, or retarget the tests in the same PR. Keep everything dormant (`registerTool`/`onToolCall`/`executeAgents`); the house rule forbids removal. Command-backend tool path (`beginToolCalls`…`gateToolCall` 3211–5250, `executeToolSynchronously` 6117–6446) stays in Chat for now. It is not engine-path and is not needed headless.
- O-2a: `WorkspaceContext::backendFor()` **must thread AgentManager/taskPool**. `Chat::selectPaletteProvider` (16920) still calls `backendFor($name, root, gate:)` without `taskManager`, so the Task tool is still dropped (N-P3 / baseline §11.1 #8). Do it once, with one owner. Per-session `NoticeSink`: `RuntimeNoticeSink` is static (`$queue` :322, cross-fork `arm()` :675), so concurrent sessions steal each other's notices.
- O-2b: the **lease already exists**. Reuse `SessionLock` (flock), not a `session_leases` table. Add only `session_events(session_id, seq, ts, type, payload)`. It shares `initEnhancedSchema` with P-A's `kind/parent_id/pinned/archived_at/title_source` migration, so land them in order. `persistTranscript` rewrites the whole transcript, and the server holds the `SessionLock` exactly as a TUI does.
- O-2e: the biggest conflict in the plan. Wave 2 rewrites the same ~2,400 lines. Either do O-2e **before** Wave 2, so Wave 2 builds inside `CompactionService`, or after it. Never do both at once.
- O-2h: `CommandResult{rows[], effects[]}`. UI-only commands get `-32030` over the wire.

**O-3a.** **Parser gap:** `ArgvParser` turns every `-`-prefixed token after a verb into `unknownFlags` (:544 → exit 2), so `serve --port 7420`, `serve stop --force`, `serve logs -f` and `serve token --rotate` cannot parse today. Add a per-subcommand flag roster (e.g. `Subcommands::SUBCOMMAND_OPTIONS['serve']`), then extend `HelpTest`'s parser scrape, the ClaimFamilies flag synopsis and the completion scripts to it. Do **not** add the serve flags to global `OPTIONS` (1135). Security defaults: 127.0.0.1 only, port 7420, mandatory token even on loopback (cookie + single-use 30 s tickets), Host/Origin guard, refuse root unless `--allow-root`, refuse to start without pcntl/posix (`doctor` probe in `Subcommands::doctorProbes` 265). Turn children close inherited server fds first.

**O-3b.** Reuse **`SugarCraft\Mcp\McpMessage`** (sugar-mcp, already required). Note that sugar-crush also carries its own `SugarCraft\Crush\McpMessage` (`src/McpMessage.php`, used by `ClaudeCodeMcpClient`/`ClaudeCodeMcpServer`). Do not add a third copy. Durable events are written to `session_events` before broadcast. Subscribe-before-snapshot. Outbox watermarks 1 MiB / 16 MiB, then close 1013. Server sessions default to `default` mode, and `bypass` is refused without `--allow-bypass`. `permission.respond remember:"project"` is refused (permission keys are user-tier only).

**O-4a.** `buildSessionDaemonCode()` emits a PHP **code string** (`sprintf`, :520) for a spawned `php`. `serve --detach` needs an **in-process** detach. `Support\Daemonize` must therefore provide both shapes from one sequence (a move, not a removal).
