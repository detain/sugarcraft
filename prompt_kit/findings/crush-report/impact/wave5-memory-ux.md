## Per-step notes

**5.1-1.** Inject the generated index, not entry bodies: user scope first, then project (repo store plus home project store). Standing instructions go with it: the types, when to save, and "don't save what the code says". Index bodies are read on demand through the 5.1-2 `view` action. The index is the operator's text, so keep `PromptFence` escaping and the two-group provenance labels from audit 15d-07. Risk: user scope leaks into every repo's prompt, the deliberate exclusion the `MemoryBlock` docblock defends. Record it as a decision; 0.6 already chose this direction. Changing the caps breaks `DocFigureProseDriftTest` :751 and N-P4d's constants (settings.md: N-P4d runs **after 5.1**).

**5.1-2.** Extract `Chat::memoryAdd`'s routing (project scope goes to `ProjectMemoryWriter::createForRoot`, falling back to the home store with a reply) into `MemoryWriter`. The slash command and the tool must not diverge. Classification decision:
- `view` and `recall` are reads.
- `save`, `str_replace` and `delete` write only harness-owned memory dirs. Classify them Allow in default and plan modes. If left as generic "Ask", every save becomes a deny in the TUI until 1.C-2 lands.

The README count hits 12 with this tool alone.

**5.2.** Run it at turn close in the parent on `summaryBackend` (tool-less, like the title and suggestion calls), throttled. The model returns JSON ops (`add` / `update` / `delete` / `skip{reason}`), and they apply through `MemoryWriter`. The redactor runs before both the request and the write. Do not run it in the fork child: memory writes from a child race the parent's `/memory` commands.

**5.3.** FTS5 is available in the local PHP build (verified with `CREATE VIRTUAL TABLE … USING fts5`), and `ext-sqlite3` is already required (composer.json :36). It still needs a no-FTS5 fallback to the existing substring search. The index is a derived cache, so hand-edited notes (MEMORY.md "### Hand-edited notes" :100) must trigger a rebuild by mtime. 5.3-2 placement: the `MemoryBlock` docblock rejects a query-dependent block in the system prompt, for per-step cost, cache prefix and placement reasons. The ranked snapshot must therefore be computed once per turn in the parent and ride the 1.A turn-context row. Embeddings degrade to BM25-only when the provider has no embedding model (SGLang often doesn't).

**5.4.**
- 5.4-1: append a journal entry where compaction summaries are produced.
- 5.4-2: git-version **only the home dir** (`~/.sugar-crush/memory`, `Bootstrap::memoryStore` :9001). Nesting a `.git` inside the repo-local `<repo>/.sugar-crush/memory` would create an embedded repository in the user's checkout. `restore` must regenerate `MEMORY.md` through `generateIndex`.
- 5.4-3: a restricted-tool engine turn (Memory and Read only), so it runs on `EngineBackend` with a filtered `turnTools`, not `summaryBackend`.

Do these after 5.2, because the redactor and op parsing are shared.

**5.5 (L, split into 5 steps).** PHP-first (5.5-1) gives value on this monorepo with no binary; ctags (5.5-2) is optional and capability-probed. PageRank needs references, not just definitions: `PhpToken` gives `T_STRING` refs, and the ctags path needs a regex identifier scan. Ship it as a tool (5.5-4) before any prompt block (5.5-5, which needs 1.A to be byte-stable). The cache lives under the home config dir, keyed by `MemoryStore::projectKeyFor`, so it never lands in the repo.

**5.6.** **Owner proposal: 5.6 owns `/context` (read-only breakdown), and it can be pulled forward to land with 2.1.** That is the natural display for 2.1's new counting of the system prompt and tool schemas. 3.B then adds "ledger / pruned / compressed blocks" rows, plus `/compress`, `/decompress` and `/sweep`, without re-defining `/context`. `/tokens` becomes an unadvertised alias (the parenthesised form in the README roster). The breakdown needs the section list in the parent: the sections are assembled inside `Runtime` in the fork child, so add a public `Runtime` accessor and call it from `Chat` with the session App (no fork).

**5.7.** Split by the 1.C dependency.

- **The Shift+Tab toggle conflicts with `shell.pane-prev`** (KeyBindingRegistry :487, KeyboardHandler :504, README :769). Pick another chord (e.g. `Alt+M`), or make Shift+Tab mode-cycle only when chat input has focus and no pane is docked. Either way, KeyBindingDriftTest needs an observation.

**5.8.** Reserve the keywords before path lookup: `@diff`, `@diff:<ref>`, `@session:<id>`, `@https://…`. A real file named `diff` must still be reachable as `@./diff`; document that precedence. `@diff` reuses `EnvironmentBlock`'s bounded, timed git runner. `@session` reads `SessionStore` transcripts and must be capped like the 256 KiB text cap. `@url` must apply WebFetch's SSRF block-list and domain rules, then go through untrusted framing (`PromptFence`).
