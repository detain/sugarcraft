## Per-step notes

**B1–B3 (all three still OPEN).**
- **B1** `sanitizeSessionRows` still hard-codes `'gitBranch' => null` (:14235).

- **B1/B3** need per-session columns. The unused `metadata` column (DDL only, `SessionStore.php:105`) is a JSON stopgap, but riding on P-A1 avoids a double migration.

**P-A1.**
- **Do not lift this design unchanged:** `forkSession` already names forks `"<name> (branch)"` (`branchName` :316, SES-2). Only the parent link (`parent_id`, `kind='branch'`) is missing.

  - The list query must stay sort-free, or the EXPLAIN pin fails.
